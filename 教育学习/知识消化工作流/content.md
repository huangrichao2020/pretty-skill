# 知识消化工作流 · 学习资料 → 多模态学习材料

> [3F Content 范式](../../content-triple-format/) · F1 源文字版 · v3.20 PDF 时代 · 教材 / PDF / 话题 → 学习材料

---

## P0 · 封面

- **章节类型**：封面
- **核心主张**：一份学习资料 = 5 种形态（笔记 / 测验 / 幻灯片 / 思维导图 / 音频）= 不同场景全覆盖
- **关键要点**：
  - 适用：PDF / 教材 / 话题 / 任意学习材料
  - 输出：5 种格式 · 按需选择
  - 适配：小学 / 初中 / 高中 / 大学 / 专业 5 个年级
  - 核心：个性化（兴趣场景 + 年级水平）
- **数据 / 数字**：5 种格式 + 5 个年级 + 4 阶段工作流
- **金句**：一份材料，五种吃法

---

## P1 · 痛点 · 学习材料效率低的 4 个根因

- **章节类型**：钩子
- **核心主张**：单一格式（只读 PDF）= 30% 吸收率 · 多模态个性化 = 80%+ 吸收率
- **关键要点**：
  - 根因 1：纯文字阅读 → 视觉型学习者吸收率 < 30%
  - 根因 2：无个性化 → 跟用户兴趣脱节 → 看完就忘
  - 根因 3：无反馈机制 → 看完了不知道掌握多少
  - 根因 4：无复习节奏 → 一次性看完 = 30 天后留存 < 10%
- **数据 / 数字**：4 个根因 · 单格式 30% vs 多模态 80%+
- **金句**：多模态 = 艾宾浩斯曲线外的第二个杠杆

---

## P2 · 5 种格式 · 各自适用场景

- **章节类型**：核心解法
- **核心主张**：5 种格式 = 不同场景的最优解 · 默认走 mindmap + slides（PDF）+ quiz
- **关键要点**：
  - **notes 笔记**：手写风格笔记 PDF · 在原文标注 或 从零生成 · 适合深度学习
  - **quiz 测验**：极简交互 HTML · 即时反馈 · 适合自测巩固
  - **slides 幻灯片**：视觉信息图风格 PDF + PPTX · 适合演示分享
  - **mindmap 思维导图**：清晰视觉层级 PNG + Mermaid 文本 · 适合快速建立框架
  - **audio 音频课程**：师生对话 mp3 · 约 15 分钟 · 适合通勤 / 运动场景
  - 默认：用户未指定 = mindmap + slides（仅 PDF）+ quiz
- **数据 / 数字**：5 种格式 / 3 种默认组合
- **金句**：场景决定格式，不是一份材料搞定所有

---

## P3 · 4 阶段工作流 · 从输入到交付

- **章节类型**：核心解法
- **核心主张**：阶段 1（输入）→ 阶段 2（解析）→ 阶段 3（生成）→ 阶段 4（统一交付）= 不可跳步
- **关键要点**：
  - **阶段 1 · 获取输入**：PDF/教材/话题 · 年级水平 · 期望格式 · 无资料 = 询问（选项 A 上传 / B 联网搜索）
  - **阶段 2 · 内容解析**：识别章节结构 · 提取核心概念 · 分析学习目标 · 输出 JSON 结构化文档
  - **阶段 3 · 顺序生成**：按用户所选格式依次执行（每种格式有独立工作流）
  - **阶段 4 · 统一交付**：`<deliver_assets>` 格式返回文件路径 · 禁止对话内嵌预览
- **数据 / 数字**：4 阶段 · 1 个 JSON 中间产物 · `<deliver_assets>` 交付格式
- **金句**：4 阶段 = 一次完整的学习材料生成

## P4 · 年级适配（小学 / 初中 / 高中 / 大学 / 专业）

- **章节类型**：核心解法
- **核心主张**：年级 = 内容深度 + 语言风格 + 视觉风格 的三维适配
- **关键要点**：
  - **小学**：活泼语气 · 简单词汇 · 鼓励性语言 · 故事化讲解 · 大字体 · 鲜艳色彩 · 趣味元素
  - **初中**：引导式提问 · 基础术语 · 青春化表达 · 图文结合 · 适中信息量
  - **高中**：深度讨论 · 逻辑推理 · 适当学术性 · 专业术语 · 数据可视化
  - **大学/专业**：研讨式对话 · 批判性思维 · 专业术语 · 学术语言 · 复杂结构 · 学术风格
  - 年级适配贯穿所有 5 种格式 · 不允许"大学语言给小学生"
- **数据 / 数字**：5 个年级 · 4 个维度（语言/内容/视觉/示例）
- **金句**：年级不是降级，是换语言

---

## P5 · 兴趣适配 · 个性化的另一杠杆

- **章节类型**：深化
- **核心主张**：用用户的兴趣领域做例子和比喻 = 吸收率提升 2x
- **关键要点**：
  - 对话 / 题目中的例子用用户兴趣领域（如游戏 / 体育 / 美食）
  - 选项内容融入用户熟悉的元素
  - 视觉风格和示例场景匹配用户兴趣
  - 图表类比使用用户熟悉的领域（股票 / 运动 / 美食等）
  - 兴趣适配需要先问用户兴趣 · 或者从对话历史推断
- **数据 / 数字**：1 个杠杆 · 4 个应用维度
- **金句**：兴趣是吸收率的隐形倍增器

## P6 · 10 条反模式 · 必避

- **章节类型**：核心解法
- **核心主张**：这 10 条是知识消化的常见错误 · 任何一条 = 退稿
- **关键要点**：
  - 内容偏离原教材（不要添加原文没有的信息或自行发挥）
  - 忽略年级适配（不要用大学水平的语言给小学生出题）
  - 笔记颜色过多（严格限制不超过 2 种颜色）
  - 测验 HTML 过度设计（保持极简 · 不用 UI 框架 / 渐变 / 阴影）
  - 幻灯片文字主导（视觉元素必须是信息载体 · 不是文字列表的装饰）
  - 幻灯片使用蓝色/紫色（除非用户明确指定 · 不用作主题色或背景色）
  - 预览/内嵌展示（生成完成后只返回文件路径 · 禁止对话预览）
  - 音频自动播放（音频文件禁止自动播放）
  - 思维导图层级过深（不超过 4 层 · 每节点不超过 10 字）
  - 幻灯片布局复制（每张基于内容独立选择可视化类型）
- **数据 / 数字**：10 条反模式
- **金句**：避错 = 80% 的质量提升

---

## P7 · 文件命名 + 交付规范

- **章节类型**：收束
- **核心主张**：命名规范统一 · 交付格式统一 · 多端覆盖
- **关键要点**：
  - 命名规则：notes `{topic}_notes.pdf` · quiz `{topic}_quiz.html` · slides `{topic}_slides.pdf/.pptx` · mindmap `{topic}_mindmap.png` · audio `{topic}_audio.mp3`
  - 图像规格：幻灯片 16:9 · 思维导图 16:9 或正方形 · PDF 150 DPI 压缩质量 90-95%
  - 交付格式：`<deliver_assets>` 包裹 · `<item><path>...</path></item>` 每项一个文件
  - 交付规则：只返回文件路径 · 禁止对话内嵌图片/PDF/音频/视频 · 中间产物不交付
- **数据 / 数字**：5 种命名规则 · 3 项规格 · 1 个交付格式
- **金句**：规范统一 = 多场景复用零摩擦
