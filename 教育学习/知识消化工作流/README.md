## 核心论点

一份学习资料 = 5 种形态（笔记 / 测验 / 幻灯片 / 思维导图 / 音频）= 不同场景全覆盖。年级（小学 / 初中 / 高中 / 大学 / 专业）+ 兴趣适配 = 个性化杠杆 = 吸收率从 30% 提升到 80%+。4 阶段工作流（输入 → 解析 → 生成 → 交付）+ 10 条反模式 = 一次完整的学习材料生成。

## 适用场景

- 教材 / PDF / 任意学习资料 → 多模态学习材料
- 不同年级（小学到专业）的个性化适配
- 不同场景（笔记 / 测验 / 演示 / 思维导图 / 音频）的全场景覆盖
- 任何"一份材料搞定所有学习场景"的需求
- 想提升学习效率 / 留存率的教师 / 学生 / 自学者

## 核心方法论（精华 4 段）

### 1 · 5 种格式 · 各自适用场景

| 格式 | 输出 | 适合 |
|---|---|---|
| notes 笔记 | `{topic}_notes.pdf` | 深度学习 · 在原文标注 |
| quiz 测验 | `{topic}_quiz.html` | 自测巩固 · 即时反馈 |
| slides 幻灯片 | `{topic}_slides.pdf/.pptx` | 演示分享 · 视觉信息图 |
| mindmap 思维导图 | `{topic}_mindmap.png` + Mermaid | 快速建立框架 |
| audio 音频课程 | `{topic}_audio.mp3` · ~15 分钟 | 通勤 / 运动场景 |
| 默认 | mindmap + slides（PDF）+ quiz | 用户未指定时 |

### 2 · 4 阶段工作流 · 不可跳步

阶段 1（输入）→ 阶段 2（解析）→ 阶段 3（生成）→ 阶段 4（统一交付）

### 3 · 5 个年级 · 三维适配

| 年级 | 语言风格 | 内容深度 | 视觉风格 |
|---|---|---|---|
| 小学 | 活泼 · 简单 · 鼓励性 · 故事化 | 简单 · 生活化 | 鲜艳色彩 · 大字体 · 趣味 |
| 初中 | 引导式提问 · 基础术语 | 适中 · 日常场景 | 图文结合 · 清晰标注 |
| 高中 | 深度 · 逻辑推理 · 学术性 | 专业术语 · 较高难度 | 数据可视化 · 专业感 |
| 大学/专业 | 研讨 · 批判 · 专业术语 | 学术 · 综合应用 | 复杂结构 · 学术风格 |

### 4 · 10 条反模式 · 必避

内容偏离原教材 / 忽略年级适配 / 笔记颜色过多 / 测验 HTML 过度设计 / 幻灯片文字主导 / 幻灯片使用蓝色紫色 / 预览内嵌展示 / 音频自动播放 / 思维导图层级过深 / 幻灯片布局复制
