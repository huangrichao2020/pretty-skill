# 教程类 H5 · 小红书小工具

> **一句话定位**：用 AI 生图 + SPA 课程架构 + 离线 H5 zip = 在小红书"小工具"发布的多课程 H5 互动产品 · 5 步走 60 分钟出活 · 跑 1 次沉淀为模板可复用

## 这个 skill 是什么

**作者**：Mavis 自沉淀 · 基于 2026-07-14 「零基础入门 AI 知识」7 节课 H5 实战
**生成日期**：2026-07-14
**风格**：杂志海报风 · 蓝白灰（Wired × MIT Tech Review 科技感）
**课程数模板**：5-7 节 · 每节 600-1200 字
**所属领域**：教育学习

## 核心论点

教程类 H5 = 离线 SPA 课程页 + AI 生图配图 + 杂志海报风视觉 + 强容器约束。H5 是"纯静态规则引擎"——❌ 用不到 LLM / 联网 / AI 推理。**讲清楚 1 个大知识点**（4 层栈 / 5 步流程 / 7 节课程）+ **SPA 多页** + **顶栏/底部导航** = 用户读完想收藏、转发、反复看。

## 适用场景

- 想在小红书"创作者中心 → 小工具"发布多课程 H5
- 主题是讲清楚 1 个大知识点（框架 / 流程 / 范式 / 体系）
- 需要支持点击看详情 + 返回 + 上一节 / 下一节
- 想沉淀 1 套模板，下一个主题直接套（"X 知识 Y 层栈"系列化）
- 长篇讲解的载体（不是"用完即弃"的工具）

## 不适用

- ❌ 需要 LLM / AI 推理的"智能工具"（H5 用不到 AI）
- ❌ 实时行情 / 联网 / 调 API 的"动态工具"
- ❌ 评分 / 测试 / 测评（用户反馈"很鸡肋"——沉淀价值低）
- ❌ 多 HTML 页面站点（容器只允许单页 + JS 视图切换）

## 5 步工作流（60-90 分钟）

```
Step 1 · 主题规划    10 分钟
        ↓
Step 2 · 内容准备    30-60 分钟（5-7 节 × 600-1200 字）
        ↓
Step 3 · 视觉准备    30 分钟（4 张 16:9 配图 + 1 张 1:1 logo）
        ↓
Step 4 · 代码编写    30 分钟（4 文件模板 + data.js 填内容）
        ↓
Step 5 · 打包上传    10 分钟（zip 规范 + 6 项自检 + 小红书后台）
```

## 4 大关键决策

1. **图必须拍平到 zip 根**（不能用 `assets/` 子目录 —— 容器 bug）
2. **JS 字符串值必须用反引号**（不能用双引号 —— 中文引号嵌套陷阱）
3. **AI 图里不放中文**（HTML 文字层覆盖 100% 准确）
4. **logo 强调主题**而不是内部框架数字（"AI" 比 "4" 更友好）

## 5 条反模式

- ❌ 评分小工具（用完即弃 + 规则型打分易失效）
- ❌ 多 HTML 页面（容器强制单页 SPA）
- ❌ 内嵌 script / 行内事件（CSP 禁 `unsafe-inline`）
- ❌ 绝对路径 / 外链（容器不联网 + 根目录不是 /）
- ❌ logo 强调内部框架数字（小白看不懂"4 层栈"）

## 6 项自检清单

打包前必走：

| # | 项 | 通过条件 |
|---|---|---|
| 1 | 包结构 | index.html 在 zip 根目录 |
| 2 | DOCTYPE / lang / charset / viewport | 4 个全有 |
| 3 | 禁用项 | 内联 script / onclick / eval / iframe / base 全 0 |
| 4 | 外链 | 0 个 `https://` 引用 |
| 5 | 路径 | 全部相对路径 `./xxx` |
| 6 | 体积 | 总包 < 3MB · 单图 < 800KB |

## 可复用模板

**`templates/`** 4 个文件可作为下次新课程的起点。

复用边角：
- 同一 [4 STYLE] 段 → 任何"科技杂志风"图都能用
- 同一 SPA 架构 → 任何"多课程 / 多文章 / 多案例"场景都能用
- 同一杂志配色（蓝白灰）→ 任何"硬核技术 / 财经 / 教育"主题都能用

## 30 分钟起步

```bash
# 1. 复制模板
cp -r templates/ my-course/
cd my-course

# 2. 写 7 节课内容到 data.js（30-60 分钟手写或 AI 辅助）
#    钩子 + 4 段 + 金句 + 行动 / 节

# 3. 生 4 张 16:9 + 1 张 1:1 logo（matrix MCP · 共享 [4 STYLE] 段）

# 4. 改 meta.title / coverImage / motto

# 5. 跑自检 + 打 zip
zip -r ../my-course.zip . -x '*.DS_Store'

# 6. 上传小红书创作者中心 → 小工具
```
