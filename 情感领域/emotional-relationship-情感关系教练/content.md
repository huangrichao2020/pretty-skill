# 情感关系教练 · 像教练一样判断局面，不讲正确废话

> 3F Content 范式 · F1 源文字版 · 把"我和她现在是什么状态、下一步怎么走"翻译成可执行动作

---

## P0 · 封面 / 定位

- **标题**：情感关系教练
- **副标**：像教练一样判断局面，不讲正确废话
- **章节类型**：封面
- **核心主张**：情感教练不是"尊重对方 / 好好沟通"的正确废话，而是能真正判断关系层级、识别信号、设计人设路线的可复用方法
- **认知锚点**：「5 层关系状态机」—— 社交 → 合作 → 依赖 / 社交 → 对抗 → 下头
- **关键要点**：
  - 默认输出 8 步：阶段 / 层级 / 信号 / 做对 / 不足 / 下一步 / 人设 / 话术
  - 必须指明优点 + 不足 + 风险 + 24h/7d/长期 3 层次指引
  - 严格避免滑向操控术（pua / 打压 / 焦虑 / 上瘾）
- **数据 / 数字**：1 个状态机 / 6 个主手册（关系层级/他心通/信号/体面表达/阶段/实操）/ 6 条红线
- **金句**：别拿依赖期的深情去打社交期的试探

## P1 · 痛点切入

- **标题**：为什么"情感"问题总是答非所问
- **副标**：正确废话 vs 可执行判断
- **章节类型**：核心解法
- **核心主张**：90% 情感建议翻车是因为没分清关系层级——把"社交期的试探"当"依赖期的深情"在打，或反过来
- **认知锚点**：「情感回答 4 大翻车坑」—— 套话 / 鸡汤 / 操控 / 复述
- **关键要点**：
  - 套话：「尊重对方 / 好好沟通」= 没回答
  - 鸡汤：「做自己 / 时间会治愈」= 等于没回答
  - 操控：pua 套路（打压、制造焦虑、嫉妒刺激）= 短期有效，长期必崩
  - 复述：把你说的话用不同词复述一遍 = 假教练
  - 真教练要做的是：判断层级、识别信号、给 24h/7d/长期指引
- **数据 / 数字**：4 大翻车坑 / 90% 答非所问率
- **金句**：把行为词翻译成情绪词，把情绪词翻译成下一步动作

## P2 · 关系层级 + 信号框架

- **标题**：5 层关系状态机 + 10 类信号
- **副标**：先分清层级，再匹配动作
- **章节类型**：核心解法
- **核心主张**：把"我和她是什么关系"压缩成 5 层状态机，把"她这个反应什么意思"压缩成 10 类信号，**先判层再动**才不会乱推进
- **认知锚点**：「5 层状态机 + 10 类信号」

```text
5 层关系状态机（核心模型）
  社交期  → 交换信号与确认信号
  合作期  → 你来我往与小型责任
  依赖期  → 稳定信任与情绪承接
  对抗期  → 安全感、边界、自主权
  下头期  → 吸引力正在崩

口诀：社交之上是合作，合作之上是依赖。社交之下是对抗，对抗之下是下头。

10 类信号识别（信号 → 正确动作）
  靠近 / 试探 / 信任 / 边界 / 退开 / 委屈 / 反馈 / 下头 / 失望 / 害怕
  → 每类：真实含义 + 关系层级 + 正确动作 + 错误动作 + 可说的话
```

- **关键要点**：
  - 误判层级的代价 = 拿依赖期的深情去打社交期 → 对方压力大到逃跑
  - 教练输出**必须**同时给 24h / 7d / 长期 3 层次
  - 抗期 = 降压 + 不自证 + 不审问
  - 下头期 = 停止追击 + 保留体面
- **数据 / 数字**：5 层 / 10 信号 / 24h·7d·长期 3 层指引
- **金句**：轻的时候轻，真的时候真

## P3 · 他心通 + 体面表达

- **标题**：他心通 = 贝叶斯预测，体面 = 经得起转述
- **副标**：猜她在想什么 + 把话说得体面
- **章节类型**：核心解法
- **核心主张**：他心通不是"读心术"，是**贝叶斯概率预测**——用历史先验 + 当前信号 + 安全余量 → 候选假设 + 支持证据 + 反证 + 动作阈值；体面表达是把"真实意图"翻译成"经得起女生转述的话"
- **认知锚点**：「他心通 + 体面表达 4 件套」

```text
他心通（贝叶斯预测）
  1 历史先验（之前她对你的整体印象）
  2 当前信号（最近 1-2 周的实际行为）
  3 候选假设（3 个可能解读 + 概率排序）
  4 动作阈值（不同概率对应不同动作，不是满概率才动）

体面表达 4 件套
  一句认领（"是我 XX 没做好"）
  一句看见她（"我能感觉到你 XX"）
  一句体面补偿（"下次我会 XX"）
  一句未来态度（"我想和你 XX"）
```

- **关键要点**：
  - 他心通 = 减少误伤 + 提前承接 + 尊重边界，**不是**操控
  - 历史记录有权重，但**当前信号最优先**（贝叶斯更新）
  - 体面 = 经得起闺蜜复盘 + 不破防 + 不低级发泄
  - 漂亮话骨架 = "人要体面，话要入耳，事要留香"
- **数据 / 数字**：4 件套 / 3 个候选假设 / 历史+信号双权重
- **金句**：不满要经得起女生转述

## P4 · 阶段手册 + 实操

- **标题**：5 阶段吸引 + 21 天低算力训练
- **副标**：从认识到热恋怎么走 / 怎么低压力社交
- **章节类型**：核心解法
- **核心主张**：吸引 = 5 阶段手册（认识初期 / 吸引期 / 暧昧期 / 拉扯期 / 热恋期），低压力社交 = 21 天低算力训练（从分析模式切到陪玩模式）
- **认知锚点**：「5 阶段 + 21 天」

```text
5 阶段吸引手册
  认识初期：交换信号 + 不抢定义
  吸引期：生命力 + 被看见感 + 留白
  暧昧期：共同体验 + 稳定节奏
  拉扯期：余味感 + 高点收住
  热恋期：双向选择 + 共同叙事

21 天低算力社交训练（从分析模式切陪玩模式）
  Day 1-7：先接球再判断
  Day 8-14：从证明切到陪玩
  Day 15-21：轻标签 + 不追问 + 高意图低索取
```

- **关键要点**：
  - 吸引不是话术堆砌，是"让对方因为你的生命力、被看见感、留白而主动补完你"
  - 21 天训练目标：后台高认知 + 前台低压力
  - 不要把"高意图"做成"高索取"（最常见误读）
- **数据 / 数字**：5 阶段 / 21 天 / 高意图·低索取
- **金句**：把控制力改写为对方自愿交出的影响力

## P5 · 默认设置 + 红线 + 怎么用

- **标题**：默认"接球模式" · 红线 6 条 · 7 大手册路由
- **副标**：拿来即用，触什么读什么
- **章节类型**：收束
- **核心主张**：情感教练 = 7 大手册路由，按用户关键词自动加载对应手册；**红线 6 条**不可破
- **认知锚点**：「7 手册路由 + 6 红线」

```text
7 大手册路由（按关键词自动加载）
  1 coaching-framework  → 通用框架
  2 relationship-layer-analysis → 层级判断
  3 mind-reading-as-prediction → 他心通
  4 signal-reading-response → 信号识别
  5 dignified-expression-beautiful-words → 体面表达
  6 attraction-stage-handbook → 5 阶段
  7 attraction-practical-playbook → 实操

6 条红线（写之前 / 写之后都自检）
  1 不制造焦虑 / 冷暴力 / 嫉妒刺激
  2 不 pua / 打压 / 价值否定
  3 不绕过拒绝（她说"不"就停）
  4 不假设唯一（她不是你的唯一选择，你也不是她的）
  5 不美化强迫 / 跟踪 / 控制 / 亲密暴力
  6 不输出"必成功 / 必挽回"承诺
```

- **关键要点**：
  - 默认走"接球模式"：她给信号，我接信号；她给信任，我给承接；她给边界，我就停手
  - 升段靠互相确认，**不靠单方推进**
  - 没到依赖期，**别开深情大招**（最常见翻车）
  - 输出必须给 24h / 7d / 长期 3 层次指引
- **数据 / 数字**：7 手册 / 6 红线 / 24h·7d·长期
- **金句**：轻的时候轻，真的时候真
