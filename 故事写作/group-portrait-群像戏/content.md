# 群像戏 · 多视角同事件的化学反应

> 3F Content 范式 · F1 源文字版 · 3 大结构法 + 1 原创 demo + 3 平台适配 · 剧本 / 小说 / 自媒体群戏通用

---

## P0 · 封面 / 定位

- **标题**：群像戏
- **副标**：多视角同事件，让 N 个角色在同一个时空里互相改变
- **核心主张**：群像 = **N 个角色 × 各自诉求 × 同一事件 × 互动产生新冲突**
- **认知锚点**：「群像戏三要点」+「群戏四要素」
- **数据**：3 大结构法 / 1 原创 demo / 3 平台适配
- **金句**：群像不是 N 个单线拼起来，是化学反应

---

## P1 · 痛点：群戏为什么难写（4 翻车坑）

```text
坑 1 · 角色没诉求  → 沦为背景板
坑 2 · 事件太单薄  → 撑不起 N 视角
坑 3 · 互动不交叉  → N 个单线拼贴
坑 4 · 缺化学反应  → 读完全文记不住任何角色
```

- **金句**：没有诉求的群像 = 一群人开会

---

## P2 · 群像三要点（核心全景）

```text
要点 1 · 每个人拥有各自诉求
  · 每个角色必须有独立的"想要什么 / 在意什么 / 怕什么"
  · 诉求要能自洽——不依赖其他角色也能成立

要点 2 · 所有人被同一事件裹挟
  · 一个核心事件把所有人拉到一起
  · 事件要够"重"——能触及每个人的诉求

要点 3 · 互动产生新的冲突
  · 角色 A 的行动 → 触发角色 B → 触发角色 C 反制
  · 冲突链 = 故事链
```

- **金句**：群像 = 化学反应

---

## P3 · 群戏四要素（戏剧密度）

```text
要素 1 · 同一目标  → 看似一致
要素 2 · 不同目的  → 制造暗流
要素 3 · 不同情绪  → 让群像有色彩
要素 4 · 然后死光  → 高潮处三方同时崩溃
```

- **密度公式**：信息量 × 角色数 × 互动次数
- **金句**：同一目标，不同目的，然后死光

---

## P4 · 原创 demo：六人饭局

> 一顿饭局，六种诉求，一个饭桌。周六晚上 7 点，A 的公寓。

### 角色诉求表

| 角色 | 诉求 | 情绪 | 行动 |
|---|---|---|---|
| **A** | 想和朋友们聚聚 | 期待 | 组局，亲自下厨 |
| **B** | 想在饭局上向 A 表白 | 紧张 | 故意坐在 A 旁边 |
| **C** | 来帮 B 表白（僚机） | 兴奋 | 配合 B 制造机会 |
| **D** | 喜欢 C，所以 C 来才来 | 故作随意 | 主动找话题跟 C 聊 |
| **E** | 想跟 D 借钱 | 焦虑 | 听说名单里有 D 就答应了 |
| **F** | 纯馋，听说 A 做饭好吃 | 轻松 | 带来一瓶好酒专心吃 |

### 互动链（8 节点）

1. **A 开门迎宾，B 拎水果进来** → B 故意撞 A 肩膀（铺垫）
2. **F 倒酒敬 A** → A 说"今天不谈工作"（隐含 A 心里有事）
3. **C 推 B 上前夹菜** → B 假装手滑烫到 → A 关心 → B 心跳加速
4. **D 观察 C 的表情**（以为 C 喜欢 B）→ 沉默 → F 开玩笑"你这杯酒敬 C 啊"
5. **E 借机问 D "最近手头宽裕吗"** → D 警觉 → C 圆场 → B 以为 C 在帮自己
6. **【死光节点】** A 突然说"其实这次约大家来，是想说我下周要离开杭州"
   - A：释然 + 忐忑 | B：崩溃（还没表白就要离开）| C：愣住
   - D：震惊 + 暗自庆幸（发现 C 没喜欢 B）| E：绝望（钱没借到）| F：吃饱了无所谓
7. **二次互动**：D 问"那 C 留下吗" → C 沉默；B 突然站起来"那我有话要说" → C 拦不住
8. **收束**：A 说"我先听完大家说" → 全场安静 → 各自摊牌

### 为什么有意思

- 6 人 6 诉求 + 1 事件 = 高密度（满足三要点 1+2）
- 每个互动都有意外（满足三要点 3）
- "我要离开"一次性触发 6 角色不同反应（死光节点）
- 喜剧 + 友情 + 爱情 + 借钱 + 离别全在一桌饭里

## P5 · 默认设置 + 3 平台适配 + 引用

### 默认设置

```text
角色数    ：3-8 人为佳
事件密度  ：每 800 字至少 1 次互动
视角切换  ：每个视角至少 100 字内心戏
死光节点  ：高潮处让所有诉求同时受冲击
风格      ：清晰 > 速度 · 出版局风格
路由      ：用户说"群像" → 本 skill；说"单线" → writing-storycraft
```

### 3 平台适配

#### 公众号长篇（5000-8000 字）
- 完整展开每个角色的内心戏（800-1000 字/角色）
- 高潮加"饭桌静默 10 秒"的极细致描写
- 适合「单读 / ONE · 一个 / 人物」调性

#### 知乎专栏（3000-5000 字）
- 用 P3 四要素法作为骨架
- 加 800 字"群像写作方法论拆解"
- 故事 + 方法论双重价值
- 适合「故事 + 方法论」类专栏

#### 小红书短篇（800-1200 字）
- 只取高潮段（A 宣布离开 + 全员反应）
- 用对话 + 短句 + 表情包模拟
- 结尾："那天晚上没人表白成功，也没人借到钱，但所有人都吃撑了"
- 适合"一口气读完"的小红书调性

### 与 writing-storycraft 的引用关系

- 引用方法 02（角色住相）作为"诉求"基础
- 引用方法 04（事件触发池）作为"同一事件"基础
- 引用方法 09（钩子回声）作为"互动产生新冲突"的伏笔机制
- **互补关系**：writing-storycraft = 单线剧情推演，群像戏 = 多视角合奏

### 4 条红线（继承自 writing-storycraft）

1. 不复述/续写/洗写未授权完整作品
2. 不写未成年人性内容
3. 不把真实普通人写成罪犯/出轨者/施暴者
4. 不美化强迫/跟踪/控制/亲密暴力
