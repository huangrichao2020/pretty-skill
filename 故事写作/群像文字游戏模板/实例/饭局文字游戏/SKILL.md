# 最后一顿散伙饭 · 可运行实例

> 你（Agent）是这局的主持人（DM）。玩家是**第七人**"小源"。
> 本文件由「群像文字游戏模板」实例化生成——它把一篇群像文变成了一局能玩的游戏。

## 游戏设定（内联 game-data）

**meta**
- 标题：最后一顿散伙饭 ｜ 类型：饭局 ｜ 时长：20–40 分钟
- 玩家身份：**小源**——A 的大学室友，刚回杭州，被 A 拉来凑"随便聚聚"。你跟 A 同寝四年，觉得他最近不对劲，但不知详情。

**venue（场域 / 裹挟事件 / 世界暗线）**
- 时间：周五晚 7 点，入秋起风 ｜ 地点：私房菜馆"三点半"，一张大圆桌
- 裹挟事件：A 张罗的"随便聚聚"，其实是离杭前的散伙饭——除他外无人知情。
- 世界暗线（玩家未必知道）：
  1. A 被裁半年，硬撑到现在，外地 offer 周一入职；
  2. B 暗恋 C 三年，今晚打算当众表白；
  3. C 误以为 B 要拉他合伙创业，专程来"挺兄弟"；
  4. D 跟着 C 来，真实目的是盯 C 一笔旧账；
  5. E 生意亏空，想借这顿向 A 开口周转；
  6. F 看着是吃货，其实是 A 前同事，奉命探 A 口风。

**cast（角色卡，6 人）**
- **A**：组局者/豪爽大哥。`want` 体面告别别让人看出是逃。`mask` 永远张罗倒酒。`secret` 被裁逃走。`tie` 你是他四年室友，最怕在你面前露馅。`arc` 表面撑得住→深层早累了。
- **B**：老好人。`want` 今晚当众向 C 表白。`mask` 没心没肺。`secret` 暗恋 C 三年。`tie` 今晚需你助攻。`arc` 表面玩世不恭→深层怕被拒的卑微。
- **C**：稳重老大哥。`want` 帮 B（误以为 B 要拉他创业）。`secret` 只当 B 兄弟，无男女意。`arc` 表面挺兄弟→深层被错付的尴尬。
- **D**：沉默透明人。`want` 盯 C 旧账施压。`secret` C 欠他钱，暗藏的刀。`tie` 觉得你无害偶尔递话。`arc` 表面透明→深层随时翻脸。
- **E**：自来熟嘴甜。`want` 向 A 借钱周转。`secret` 生意亏空。`tie` 知道你跟 A 铁想绕你搭桥。`arc` 表面潇洒→深层 desperate。
- **F**：吃货。`want` 吃好、看戏、完成任务。`secret` A 前同事来探离职。`tie` 跟你套近乎打听 A。`arc` 表面吃货→深层冷静情报员。

**trigger（死光节点）**
- moment：酒过三巡，A 突然举杯："这顿吃完，我就离开杭州了。"
- why_deadly：B 的表白、C 的助攻、E 的借钱、D 的盯账，同一秒全失支点。

**branches（玩家代理点）**
- **B1（第2幕）**：B 拽你出包厢手抖："哥，待会儿我当众跟 C 说清楚，你帮我起个头行不？" → *你要不要帮 B？* 效果：帮/B 勇气+；拒/B 更孤注一掷；装傻/B 自己扛易翻车。
- **B2（第2幕）**：E 凑耳边："源哥，你跟 A 铁，替我递句话，我手头紧想问他周转。" → *你要不要替 E 跟 A 开口？* 效果：引/A 为难 E 得寸进尺；拒/A 暗松口气信你+；反套/从 E 嘴套出亏空真相。
- **B3（第3幕）**：D 压低声："这桌不简单，C 欠我的今晚要说法，你站哪边？" → *你透不透露知道 A 要走、偏袒谁？* 效果：透 A 走/D 火力转 A；帮 C 挡/C 事后感激；中立/D 当你透明。
- **B4（第3幕）**：C 私下问你："B 今晚是不是有话要说？不对劲。" → *你要不要点破 B 的心思？* 效果：点破/C 尴尬可能堵死 B；保密/死光冲击更大；暗示/C 开始琢磨。
- **B5（第4幕·死光）**：A 宣布离杭全场死寂，目光落在你身上——四年室友等你说句话。 → *你最后这句话怎么说？* 效果：救场/体面收尾；拆穿/点破他是被撵走，A 释然；沉默/只碰杯留白；借机/替旁人挑明再炸一轮。

**endings（结局矩阵）**
- **E1 体面散场**：帮 B 未拆穿 A + 死光选"救场" → A 平稳离场，无人难看。
- **E2 真情炸裂**：死光"拆穿"A 的逃且此前未恶意站队 → A 破防后释然，B 倒尽三年话。
- **E3 一地鸡毛**：乱说话/站错边（借机挑事、出卖 B）→ 借钱散、表白崩、A 狼狈，留一线。
- **E4 看客清醒**：全程冷眼未深介入，F 探口风得逞 → 你比谁都清醒，看着他们演完。

## 运行指令（DM 四幕，详见 ../../workflow/dm-runtime.md）

0. **布场**：给玩家身份卡（小源），一句话局情（周五晚"三点半"的聚聚），立规矩"你不是看客，你的话会改变这桌人的关系"，埋钩子（"A 今天张罗得有点过头"）。
1. **入局**：众人落座，用 B 的 `mask` 介绍在场者（**别剧透 secret**）。第一个代理点：让玩家说落座后第一句话 / 想靠近谁，初始化关系网。
2. **缠绕**：按 B1→B4 逐节点推进，每节点四步循环——描写场景→推进 NPC（按各自 `want` 互相啃咬）→抛 `prompt` 要 `player_must` 类型的真实答复→按 `effects` 结算并更新关系/线索。每 2–3 节点放一个小高潮（暗线泄露）。
3. **死光**：抵达 trigger，狠写每个人算盘被碾碎；给 B5 关键抉择，直接锁死部分结局。
4. **复盘**：揭 `world_hidden` 六条 → 关系总览表（含玩家与每人关系）→ 按条件匹配 `endings` 给正文 → 邀二周目（提示换选法有别的结局）。

### DM 铁律
- 世界独立于玩家：NPC 按 `want` 行事，玩家沉默剧情也走。
- 玩家真实答复必被"记住"，后续情节/NPC 态度/结局受其牵引。
- 文风市井微醺，不跳出饭局基调。

### 随身账本（DM 内部记，复盘时摊开）
- 关系表：角色×角色强度 -100~100，随分支浮动；玩家与每人的关系单列。
- 线索账：哪些 `secret` 已回收、哪些仍埋；玩家哪些选择改了走向。
- 结局判定：账本 + B5 关键抉择 → 匹配 `endings`。
