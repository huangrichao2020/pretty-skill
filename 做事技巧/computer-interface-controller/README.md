## 核心论点

GUI 自动化不该写脚本调用 native API · computer-interface-controller = 视觉 + 语义驱动 · 支持点击按钮 / 输入文字 / 分析屏幕 / 填写表单 · 跨平台（本地 + 远程）。

## 核心方法论（4 段）

### 1 · 触发场景
- 自动化桌面操作 / GUI 自动化 / 点击按钮 / 输入文字 / 分析屏幕 / 填写表单 / 管理文件 / 控制浏览器

### 2 · 4 项核心能力
- 视觉识别（截图 → 元素定位）
- 语义理解（按名字 / 类型查找元素）
- 操作执行（点击 / 输入 / 滚动 / 拖拽）
- 反馈验证（操作后截图确认）

### 3 · 工作流（5 步）
启动会话 → 截图分析 → 元素定位 → 执行操作 → 截图验证

### 4 · 4 大反模式
- ❌ 写 native API 脚本（pyautogui）→ 平台耦合
- ❌ 用固定坐标 → 界面变化失效
- ❌ 不截图验证 → 不知道成功没有
- ❌ 单步执行不循环 → 大量重复劳动
