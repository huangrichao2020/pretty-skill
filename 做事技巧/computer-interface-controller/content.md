# 电脑界面操控 · GUI 自动化

> [3F Content 范式](../../content-triple-format/) · F1 源文字版

## P0 · 封面
- 自动化桌面操作 · 视觉 + 语义驱动 · 跨平台 · 点击 / 输入 / 截图

## P1 · 痛点 · GUI 自动化的 4 个常见错误
- 写 native API 脚本（pyautogui）→ 平台耦合
- 用固定坐标 → 界面变化失效
- 不截图验证 → 不知道成功没有
- 单步执行不循环 → 大量重复劳动

## P2 · 4 项核心能力
- 视觉识别（截图 → 元素定位）
- 语义理解（按名字 / 类型查找元素）
- 操作执行（点击 / 输入 / 滚动 / 拖拽）
- 反馈验证（操作后截图确认）

## P3 · 5 步工作流
启动会话 → 截图分析 → 元素定位 → 执行操作 → 截图验证

## P4 · 与脚本自动化差异
- computer-interface-controller：视觉 + 语义 · 跨平台 · 鲁棒
- 脚本自动化（pyautogui）：固定坐标 · 平台绑定 · 易碎
