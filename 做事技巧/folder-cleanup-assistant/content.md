# 文件夹整理助手 · 安全清理 + 备份

> [3F Content 范式](../../content-triple-format/) · F1 源文字版

## P0 · 封面
- 文件整理 = 不可逆操作 · folder-cleanup-assistant = 清理前自动备份 + 移动代替删除

## P1 · 痛点 · rm -rf 的 3 大风险
- 误删重要文件 = 不可恢复
- 没有清理前备份 = 出错没退路
- 系统文件被误删 = 系统崩溃

## P2 · 3 大原则
- 清理前自动压缩备份
- 用移动代替删除（mavis-trash）
- 桌面端使用 · 跨平台

## P3 · 4 步工作流
扫描目录结构 → 识别大文件 / 重复文件 / 临时文件 → 压缩备份 → 移动到指定位置

## P4 · 反模式
- ❌ 直接 rm -rf
- ❌ 不做备份
- ❌ 跨平台用同一脚本（权限/编码差异）
