## 核心论点

文件整理 = 不可逆操作 · folder-cleanup-assistant = 清理前自动压缩备份 + 用移动命令代替删除 = 出错可恢复。

## 核心方法论

### 1 · 触发关键词
"文件整理" / "文件夹清理" / "清理文件" / "整理目录" / "folder cleanup" / "organize files"

### 2 · 3 大原则
- ✅ 清理前自动压缩备份（保留原结构）
- ✅ 用移动代替删除（mavis-trash 而不是 rm）
- ✅ 桌面端使用（跨 Mac/Linux/Windows）

### 3 · 工作流（4 步）
扫描目录结构 → 识别大文件 / 重复文件 / 临时文件 → 压缩备份 → 移动到指定位置

### 4 · 与 rm -rf 差异
folder-cleanup-assistant = 安全 + 可恢复 · rm -rf = 危险 + 不可逆
