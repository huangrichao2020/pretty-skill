## 核心论点

读文档不该用复制粘贴 · doc-reader 把 Office 文档（DOCX/XLSX/PDF）转成纯文本 + 保留结构 + 提取关键信息 = 后续 LLM 直接消化。

## 适用场景

- 用户上传 .docx/.xlsx/.pdf 文件
- 要求"读取 / 查看 / 提取 / 分析" 文档内容
- 把文档喂给 LLM 做后续处理
- 提取文档结构 + 表格 + 图片信息

## 核心方法论（精华 4 段）

### 1 · 触发场景（4 类）

| 场景 | 触发词 |
|---|---|
| 用户上传文件 | "读取这个文档" |
| 文件信息提取 | "提取 PDF 内容 / 看看这文档里有什么" |
| 内容分析 | "分析这个文档 / 帮我读一下" |
| 格式转换 | "转成 md / 转成纯文本" |

### 2 · 支持格式（3 大类）

- **Office 文档**：DOCX（Word）/ XLSX（Excel）
- **PDF 文件**：含扫描件 OCR
- **其他**：通过 markdown-converter 扩展

### 3 · 提取能力（5 项）

- ✅ 纯文本提取（保留段落结构）
- ✅ 表格识别（XLSX 直接转 DataFrame）
- ✅ 图片提取（嵌入图片 base64）
- ✅ 元数据保留（作者 / 创建时间 / 页数）
- ✅ 章节结构识别（标题层级 / 目录）

### 4 · 5 大反模式

- ❌ 不要用复制粘贴（破坏格式）
- ❌ 不要用 OCR 工具（PDF 已经是文本）
- ❌ 不要忽略图片（很多内容在图里）
- ❌ 不要丢元数据（影响后续引用）
- ❌ 不要做"半截"提取（只提取文字不提取表格）
