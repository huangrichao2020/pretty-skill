# 文档读取助手 · 锦绣素材

## 导语

读文档不该用复制粘贴 —— 复制粘贴破坏格式、丢表格、丢图片、丢元数据。doc-reader 把 Office 文档（DOCX/XLSX/PDF）转成纯文本 + 保留结构 + 提取关键信息 = 后续 LLM 直接消化。

## 5 项提取能力 · 一张图看懂

| 能力 | 解决什么问题 |
|---|---|
| 纯文本提取 | 文字搬过来不丢段落 |
| 表格识别 | XLSX 表格不变成乱码 |
| 图片提取 | 30% 内容在图里不能丢 |
| 元数据保留 | 后续引用有源头 |
| 章节结构识别 | 标题层级 / 目录完整 |

## 收尾 · 好文档 = AI 能读 + 人能读

下次收到 .docx/.xlsx/.pdf 的时候，先问自己：我要的是"搬文字"还是"搬结构"？前者 OCR 够用，后者 doc-reader 才够。
