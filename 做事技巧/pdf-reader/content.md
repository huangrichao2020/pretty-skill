## P1 · 痛点 · PDF 处理的 4 大难题

- **标题**：PDF 处理的 4 大难题
- **副标**：加密 / 扫描 / 复杂表格 / 大文件
- **章节类型**：钩子
- **核心主张**：PDF 难读不是因为格式，是因为 4 类场景
- **关键要点**：
  - 难题 1：加密 PDF（密码 / 权限）
  - 难题 2：扫描 PDF（图片）
  - 难题 3：复杂表格（合并单元格）
  - 难题 4：大文件（> 100 MB）
- **数据 / 数字**：4 难题 / 0 类通用解
- **金句**：PDF 是文档之王但也是最难读。

- 难题 1：扫描件 PDF = 图片 + OCR 准确率 80-90%
- 难题 2：复杂排版（双栏 / 表格 / 嵌入字体）= 文本顺序乱
- 难题 3：加密 PDF = 密码保护
- 难题 4：大文件（100+ 页）= 内存溢出 + 速度慢
- **认知锚点**：「4 大 PDF 难题」—— 加密/扫描/复杂表格/大文件

## P4 · 与 doc-reader / OCR 工具差异

- **标题**：与 doc-reader / OCR 工具差异
- **副标**：PDF = 难读；doc = 易读；OCR = 扫描识别
- **章节类型**：深化
- **核心主张**：选对工具 = 10 倍效率
- **关键要点**：
  - pdf-reader：处理 PDF（含扫描/加密）
  - doc-reader：处理 DOCX（结构好）
  - OCR：纯图片转文本
- **数据 / 数字**：3 工具 / 互补不重叠
- **金句**：工具选错 = 拿扳手拧螺丝。

| 工具 | 适用 |
|---|---|
| pdf-reader | PDF 全场景（文本 + 扫描件 + 加密 + 复杂排版）|
| doc-reader | 多格式通用（DOCX/XLSX/PDF）|
| OCR 工具 | 纯扫描件 → 文字（慢 + 准确率有限）|
- **认知锚点**：「工具差异对比表」—— pdf-reader/doc-reader/OCR
