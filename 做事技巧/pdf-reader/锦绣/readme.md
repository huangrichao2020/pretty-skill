# PDF 读取技能 · 锦绣素材

## 导语

PDF 是文档格式之王，但也是最难读的格式 —— 扫描件、复杂排版、加密、大文件，每一类都是单独的难题。pdf-reader 把全文提取、结构分析、关键信息搜索、摘要生成 4 件事打包 = 一站式 PDF 处理。

## 5 步工作流 · 一张图看懂

1. 识别类型（文本 / 扫描件 / 加密 / 复杂排版）
2. 选工具（pdfplumber / PyPDF2 / Tesseract OCR / pdf-crypto）
3. 分页提取（避免内存溢出）
4. 合并 + 清理（去页眉页脚 / 修复顺序）
5. 输出结构化结果（JSON / Markdown）
