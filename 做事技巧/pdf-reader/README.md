## 核心论点

PDF = 文档格式之王 · 但也是最难读的格式 · pdf-reader 把全文提取 + 结构分析 + 关键信息搜索 4 件事打包 = 一站式 PDF 处理。

## 适用场景

- 提取 PDF 全文 / 摘要 / 关键信息
- 分析 PDF 文档结构（章节 / 表格 / 图）
- 搜索 PDF 内特定关键词
- 把 PDF 喂给 LLM 做 RAG

## 核心方法论（4 段）

### 1 · 触发短语（7 类）
"读取 PDF" / "提取 PDF 内容" / "分析 PDF" / "PDF 文件内容" / "PDF 内容提取" / "总结 PDF" / "PDF 关键信息"

### 2 · 4 项核心能力
- 全文提取（按页 / 整篇）
- 文档结构分析（标题层级 / 章节 / 目录）
- 关键信息搜索（关键词定位 + 上下文）
- 摘要生成（自动总结要点）

### 3 · 工作流（5 步）
识别 PDF 类型（文本 / 扫描件）→ 选择工具（pdfplumber / PyPDF2 / Tesseract OCR）→ 分页提取 → 合并 + 清理 → 输出结构化结果

### 4 · 与 doc-reader 差异
pdf-reader 专注 PDF · 处理扫描件 / 加密 / 复杂排版 / OCR 整合 · doc-reader 是通用多格式
