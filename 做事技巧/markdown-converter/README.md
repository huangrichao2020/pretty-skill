## 核心论点

格式转换不该是体力活 · markdown-converter 支持 PDF / Word / PPT / Excel / 图片 / 音频 / ZIP / YouTube 等 20+ 格式 → Markdown = 一键转 = LLM 可读。

## 核心方法论（4 段）

### 1 · 支持格式（20+ 类）
PDF / Word（DOCX）/ PPT（PPTX）/ Excel（XLSX）/ 图片 / 音频 / ZIP / YouTube / EPUB / HTML / CSV / JSON / Markdown / ...

### 2 · 工作流（3 步）
识别格式 → 选转换器（按文件类型）→ 输出 Markdown（保留结构 + 嵌入资源）

### 3 · 关键能力（6 项）
- ✅ 表格识别（保留表格结构）
- ✅ 图片嵌入（base64 内联）
- ✅ 公式识别（LaTeX 输出）
- ✅ 代码块识别（语言高亮保留）
- ✅ 章节结构（标题层级）
- ✅ 元数据保留（作者 / 创建时间）

### 4 · 与 doc-reader / pdf-reader 差异
markdown-converter 范围最广（20+ 格式） · 精度比 doc-reader/pdf-reader 低（专精度不如专精工具） · 适合"快速转 markdown 不挑格式"场景
