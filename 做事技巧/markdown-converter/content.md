> [3F Content 范式](../../content-triple-format/) · F1 源文字版

## P0 · 封面
- **核心主张**：格式转换不该是体力活 · markdown-converter = 20+ 格式 → Markdown 一键转
- **认知锚点**：「格式转换 4 步漏斗」—— 读-转-验-出
- **支持**：PDF / DOCX / PPTX / XLSX / 图片 / 音频 / ZIP / YouTube 等

## P1 · 痛点 · 格式转换的 4 个常见错误
- 错误 1：手动复制粘贴 → 格式破坏
- 错误 2：用在线工具 → 上传公司机密数据
- 错误 3：丢图片 / 公式 / 表格
- 错误 4：转换后还要二次处理
- **认知锚点**：「4 大转换错误」—— 编码乱/样式丢/链接断/图丢

## P2 · 6 项关键能力
- 表格识别 / 图片嵌入 / 公式识别 / 代码块识别 / 章节结构 / 元数据保留
- **认知锚点**：「6 项关键能力」—— 编码/样式/链接/图/表格/代码

## P3 · 工作流
识别格式 → 选转换器 → 输出 Markdown（保留结构 + 嵌入资源）
- **认知锚点**：「工作流传送带」—— 读-转-验-出

## P4 · 与专精工具差异
- markdown-converter：范围广 · 精度中等
- doc-reader / pdf-reader：专精度高 · 范围窄
- 按场景选择（快速转换 vs 专业提取）

完整规范：[README.md](../README.md)
- **认知锚点**：「专精工具差异」—— 与 pandoc/mark-2-html 对比
