## 核心方法论

### 1 · 4 件套
- **docx**：读取 / 生成 / 模板应用 / 编辑填充 / 修复 / 对比 Word
- **xlsx**：读取 / 编辑 / 创建 / 转换 Excel
- **pdf**：生成 / 重排 / 填充 / 读取 PDF
- **pptx**：读取 / 创建 / 编辑 PPTX

### 2 · 6 大能力
- 读取（parse / 提取内容 / 检查主题）
- 创建（PptxGenJS / python-docx）
- 编辑（保留格式填充）
- 修复（修复损坏文档）
- 对比（diff）
- 重排（重新格式化）

### 3 · 触发场景
- 正式 Word 交付物
- DOCX 诊断 / 修复
- Excel 数据处理
- PDF 生成 / 转换
- PPT 创建 / 编辑

### 4 · 与单文件 skill 差异
office-document-specialist-suite = 4 件套打包 · 统一规范 · 内置模板 · 比 doc-reader / pdf-reader 范围广
