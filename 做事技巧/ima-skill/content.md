# IMA 笔记管理 · 知识库统一管理

> [3F Content 范式](../../content-triple-format/) · F1 源文字版

## P0 · 封面
- 知识库 = 个人第二大脑 · ima-skill = 统一 IMA OpenAPI · 6 类操作

## P1 · 痛点 · 笔记管理的 4 个常见问题
- 工具太多（Notion / Obsidian / 印象笔记 / 备忘录）→ 分散
- 知识搜索难 → 找不到之前收藏的内容
- 文件上传失败 → API 限制
- 笔记创建繁琐 → 不愿意用

## P2 · 6 类操作
- 上传（文件 / 网页到知识库）
- 搜索（关键词 / 语义）
- 浏览（笔记列表）
- 创建（新笔记）
- 编辑（已有笔记）
- 收藏（网页一键入知识库）

## P3 · 3 步工作流
登录授权 → 选择操作类型 → 执行 + 返回结果

## P4 · 智能识别
涉及文件上传到知识库 / 网页收藏 / 知识搜索 / 个人文档存取 → 都触发 ima-skill
