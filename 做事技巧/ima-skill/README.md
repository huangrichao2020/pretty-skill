## 核心方法论

### 1 · 触发场景（6 类）
- 知识库 / 资料库 / 笔记 / 备忘录 / 记事
- 上传文件 / 添加网页到知识库
- 搜索知识库内容 / 浏览 / 创建 / 编辑笔记

### 2 · 6 类操作
- 上传（文件 / 网页到知识库）
- 搜索（关键词 / 语义）
- 浏览（笔记列表）
- 创建（新笔记）
- 编辑（已有笔记）
- 收藏（网页一键入知识库）

### 3 · 智能识别
即使没明确说"知识库"或"笔记"，只要涉及：
- 文件上传到知识库
- 网页收藏
- 知识搜索
- 个人文档存取

→ 都触发 ima-skill

### 4 · 工作流（3 步）
登录授权 → 选择操作类型 → 执行 + 返回结果
