## 💎 项目哲学（v3.3 升级）

> **清晰 > 速度 · 让人看得懂 > 快速生成**

之前的 AI 工具（包括 Mavis 自己）都在追求"**自动化**"和"**快速生成**"——但这恰恰是**优秀知识没人用的根因**：

| 主流方向 | pretty-skill 方向 |
|---|---|
| 快速生成 skill SOP | 多花几分钟讲清楚 |
| 自动化 = 省时间 | 清晰 = 让人看得懂 |
| 知识越快越好 | 知识被看懂才好 |
| 工具 = 减少工作量 | 工具 = 增加可读性 |

> **我们不追求"快速生成 SOP"**。我们追求"**多花 5 分钟，让你的知识被人真正看懂**"。

这就是 **"锦绣"** 存在的意义——把任何知识"绣"成易传播的视觉作品 = 让人看得懂。

## 💡 是什么

pretty-skill 是一个**开源项目**：集合**全世界开发者与玩家**贡献的优质**技能 / 知识**。

- **AI 友好**：3F Content 范式 = `.md` 源文字（AI 能直接消化）
- **人易传播**：锦绣范式 = 2 封面 + 8-12 讲解图 + 1 融合 md（人一眼懂 + 易分享）
- **演示通用**：PPT 版 HTML 必填 = 任何浏览器打开 + 键盘翻页 + 全屏 + 演讲者模式
- **全球共建**：11 中文领域预设 + 允许新增领域 + skill-creator 工具

任何开发者 / 玩家 / 研究者都可以把自己做好的 skill 或知识贡献到这个项目，按统一的"3F Content + 锦绣"范式发布。

> **做"被看懂的知识"，不做"被产出的知识"**。

**多花 30 分钟 = 100 倍可懂性提升**。这就是这个项目的真正价值。

## 🌟 "锦绣"概念（v3 核心）

> **锦绣（Jinxiu）= 把任何知识 / skill 在创建时就"绣"成易传播的视觉作品**

**锦绣存在的理由**：

> 大量优秀的 skill 或知识做出来，没人用，因为没人看得懂。
> 锦绣 = **让知识被人真正看懂** = 多花 5 分钟生成能讲解清楚的图片、封面、pptx、html

**核心原则**：
- **不追求快速生成 SOP**
- **多花几分钟**生成能讲解清楚你的 skill 或知识的图片
- **方便人看和学** = 才是一直被忽视的重要东西

**v3.1 简化结构**（按形式切 · 不锁死平台）：

```
锦绣/
├── cover-横屏.png       # 1 张横屏封面（16:9 · 朋友圈/推特/微博）
├── cover-竖屏.png       # 1 张竖屏封面（3:4 或 9:16 · 小红书/抖音）
├── slides/              # 8-12 张讲解图（creator 自行决定）
└── readme.md            # 1 份融合 md（公众号 + 自媒体稿 + AI 阅读）
```

**readme.md 融合 3 用途**：
- 直接发公众号
- 当自媒体讲解稿
- AI 阅读使用

完整规范：[content-triple-format/锦绣.md](./content-triple-format/锦绣.md)

## 🛠️ 范式：3F Content + 锦绣（v3.2 必填 / 可选清单）

```
<领域>/<case>/
├── content.md            # F1 · 源文字（**必填** · 人类 + AI 最高兼容）
├── web.html              # F2 · PPT 演示版 HTML（**必填** · 演示场景）
├── presentation.pptx     # F3 · PowerPoint（**可选** · 仅二次编辑时生成）
├── images/               # AI 出图原图（**必填**）
├── prompts/              # 出图 prompt 文件（**必填**）
└── 锦绣/                 # 传播素材（**必填**）
```

**v3.2 关键决策**：
- ✅ `web.html` = **PPT 演示版**（必填 · 替代 .pptx 作为演示载体）
- ⚠️ `presentation.pptx` = **可选**（90% 用户不需要 · 仅当要二次编辑时才生成 · 加 `--with-pptx` 标志）

**v3 关键决策**：
- ✅ 3F Content = AI 友好（content.md 让 LLM 能消化）
- ✅ 锦绣 = 人易传播（视觉化让人看得懂）

完整规范：[content-triple-format/README.md](./content-triple-format/README.md)

## 🚀 如何贡献（开发者 + 玩家）

### 5 步贡献一个 skill

1. **想清楚**：你的知识要解决什么问题？（不要急着写）
2. **写 content.md**（4-7 字段/页 · **多花几分钟讲清楚**）
3. **出 AI 图**（matrix / DALL-E / Midjourney）→ 嵌进 web.html
4. **跑 check-3f.py**（确保 3 件套 + 锦绣全有）
5. **提 PR**（PR 模板自动给 11 领域下拉）

**关键心态**：不要追求快，**多花 5 分钟讲清楚 = 100 倍可懂性**。

完整流程：[CONTRIBUTING.md](./CONTRIBUTING.md)

### 想新增 1 个领域？

PR 加 `新领域/README.md` + `新领域/<至少 1 个 case>/` = 仓库主审核。**全球开发者可以共建领域清单**。
