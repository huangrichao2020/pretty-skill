## 这个 case 是什么

**页数**：4 页 · **领域**：内容创作

## 核心论点

公众号文章不该凭空写 · wechat-article-creator = 热点采集 + 灵感提取 + 4 类风格 + 配图 + 发布建议 · 完整闭环。

## 5 步工作流

1. 热点采集（热门话题 + 爆款文章分析）
2. 灵感提取（结构/标题/开头/收尾模式）
3. 大纲设计（钩子 + 主体 + CTA）
4. 正文生成（4 类风格：干货/情感/热点/故事）
5. 配图 + 发布建议（配图位置 + 最佳发布时间）

## 4 类文章风格

- 干货分享（知识科普/技能教程/经验总结）
- 情感共鸣（故事叙述/观点表达/生活感悟）
- 热点解读（时事评论/行业分析/趋势洞察）
- 故事叙述（真实故事/人物特写/案例分析）

## 输出规范

```
【标题】主标题 + 副标题

```
