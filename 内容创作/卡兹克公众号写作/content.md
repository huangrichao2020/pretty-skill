## P1 · 痛点 · AI 代笔的 5 个隐藏陷阱

- **章节类型**：钩子
- **核心主张**：AI 能写出语法正确的文章，但写不出让人读完想用的文章
- **关键要点**：
  - 套话陷阱："说白了""本质上""这意味着" 一出现立刻暴露
  - 标点陷阱：冒号 / 破折号 / 双引号 = AI 三大标志
  - 教科书开头陷阱："在当今 AI 快速发展的时代" = 一秒劝退
  - 空泛工具名陷阱：不说具体名字（Claude Code / Codex / Seedance 2.0）= 没真用过
  - 假设性例子陷阱："比如有一次..." 这种编造场景 = 大忌
- **数据 / 数字**：5 个隐藏陷阱
- **金句**：一个活人的体感记忆，AI 永远学不来

## P2 · 5 种文章原型

- **章节类型**：核心解法
- **核心主张**：写之前先判断属于哪种原型，每种的写法重心不同
- **关键要点**：
  - 调查实验型："我替你去做了这件事" · 重心：过程叙事 + 层层递进（买 9.9 DeepSeek）
  - 产品体验型："跟我一起玩" · 重心：场景演示 + 真实感受（miclaw 手机 Agent）
  - 现象解读型："你注意到了吗？背后是什么？" · 重心：观察→好奇→研究→升维（AI 看不到爱心）
  - 工具分享型："我发现了一个好东西" · 重心：故事铺垫→工具展示→效果惊艳（天赋挖掘 Prompt）
  - 方法论分享型："压箱底的东西掏给你了" · 重心：每节有可执行动作 + 坦诚失败点
- **数据 / 数字**：5 种原型 / 每种配 1 个真实案例
- **金句**：先判断原型，再动笔

## P3 · 风格内核 · 活人感的 7 大基因

- **章节类型**：核心解法
- **核心主张**：活人感 = 节奏 + 故意打破 + 知识"聊着聊着掏出来"+ 私人视角 + 判断力 + 对立面承认 + 亲自下场
- **关键要点**：
  - 节奏：跟朋友聊天，不像写报告（长短句交替 + 一句话独立成段）
  - 论述中的故意打破：重复强调 / 中途叹息 / 省略主语 / 刻意模糊
  - 知识输出方式："聊着聊着顺手掏出来"，不是"下面我来给大家科普一下"
  - 私人视角：用"我也面临这个问题"代替"这给我们的启示是"
  - 判断力：敢下判断 + "我被打动了"姿态
  - 对立面承认：先站到对方角度把对方处境具体化 + 承认合理 + 再切入自己视角
  - 亲自下场：让读者感觉到"这个人真的做了这件事"
- **数据 / 数字**：7 大基因 / 11 大风格技巧（契诃夫之枪 / 升番逻辑 / 文化升维 / 读者直呼 / 疑问句节奏 / 层层剥开 / 英雄之旅 / 反向论证 / 谦逊铺垫 / 句式断裂 / 人物画像法）
- **金句**：活人感 = 不完美 + 私人 + 有温度

## P4 · 绝对禁区（卡兹克 AI 味检测 6 类）

- **章节类型**：核心解法
- **核心主张**：这 6 类表达 = 100% AI 标志 = 退稿
- **关键要点**：
  - 套话：禁用"首先...其次...最后""综上所述""值得注意的是""不难发现""让我们来看看""接下来让我们"
  - 过度结构化：不用 bullet 罗列、不大量加粗、不加小标题（除 N 条心得型）
  - 标点禁令：不使用冒号 / 破折号 / 任何双引号（用「」或不加）
  - 高频踩雷词：禁用"说白了""意味着什么？""这意味着""本质上""换句话说""不可否认"
  - 假设性例子："比如有一次..." 这种编造 = 大忌
  - 空泛工具名：不说"AI 工具""某个模型"·要说 Claude Code / Codex / Seedance 2.0 等
- **数据 / 数字**：6 类禁区 / 5 类禁用标点 / 6 个高频踩雷词
- **金句**：禁区每踩一个，活人感掉一档

## P5 · 4 层自检体系（卡兹克质检 · 软件工程测试金字塔）

- **章节类型**：深化
- **核心主张**：写完必须跑完整个 4 层质检流程，每层都有明确通过标准 + 修复指引
- **关键要点**：
  - **L1 硬性规则**（自动扫描）：禁用词 / 禁用标点 / 结构套话 / 空泛工具名 = 零命中
  - **L2 风格一致性**（模式匹配）：开头 / 节奏 / 口语化 / 标点禁令 = 至少 3/4 通过
  - **L3 内容质量**（深度审查）：观点支撑 / 知识输出方式 / 文化升维 / 对立面同理心 / 类型专项 / 逐一展示 = 关键项全过
  - **L4 活人感终审**（最终人格层）：温度 / 独特性 / 姿态 / 心流 = "这像是真人写的"
  - 通过标准：4 层全部通过 → 文章达标；任何一层不过 → 返工
- **数据 / 数字**：4 层 / 19 项检查
- **金句**：测试金字塔的活人感版本

## P6 · 开头 + 结构 + 字数

- **章节类型**：收束
- **核心主张**：开头从具体事件切入 · 结构靠口语化转场 · 字数 4000-8000
- **关键要点**：
  - 开头必杀技：叙事启动"故事是这样的" / 荒诞事实 / 热点破题 / 好奇心驱动 · 绝不宏大叙事
  - 结构模板：感性切入 → 背景铺垫（聊天式）→ 核心内容 → 升华（聊着聊着想起来的）→ 收尾（5 种收法）
  - 收尾 5 种：引用收尾 / 哲思余韵 / 行动呼吁 / 信念宣言 / 回环呼应
  - 字数 4000-8000 · 段落短（一句话成段）· 重要观点前后留白
  - **不加小标题** · 靠口语化转场自然衔接（"说到这个""回到 xxx 这块""顺着上面的再聊聊"）
  - 固定尾部：星标⭐ + 在看 + 转发三连 + "我们，下次再见"
- **数据 / 数字**：4000-8000 字 / 5 种收法 / 固定尾部 7 元素
- **金句**：写得让人读完想用 = 卡兹克写法的唯一验收
