## 核心论点

AI 能写出语法正确的文章，但写不出让人读完想用的文章。卡兹克风格 = 5 种文章原型 + 7 大风格内核 + 4 层自检体系 + 6 类绝对禁区 + 5 种开头必杀技 + 5 种收尾 · 任何人按这套范式写出"卡兹克级"活人感公众号长文。

## 适用场景

- 公众号长文写作（4000-8000 字 · 叙事驱动）
- AI 行业 / 科技 / 创业 / 设计领域的内容创作者
- 想要"活人感"但被 AI 模板味困住的写作者

## 核心方法论（精华 4 段）

### 1 · 5 种文章原型（先判断再动笔）

| 原型 | 核心动作 | 写法重心 | 真实案例 |
|---|---|---|---|
| 调查实验型 | 我替你去做了这件事 | 过程叙事 + 层层递进 | 买 9.9 DeepSeek |
| 产品体验型 | 跟我一起玩 | 场景演示 + 真实感受 | miclaw 手机 Agent |
| 现象解读型 | 你注意到了吗？背后是什么？ | 观察→好奇→研究→升维 | AI 看不到爱心 |
| 工具分享型 | 我发现了一个好东西 | 故事铺垫→工具展示→效果惊艳 | 天赋挖掘 Prompt |
| 方法论分享型 | 压箱底的东西掏给你了 | 每节有可执行动作 + 坦诚失败点 | 用 AI 三年 9 条心得 |

### 2 · 7 大风格内核（活人感的不可拆解）

节奏 + 故意打破 + 知识"聊着聊着掏出来"+ 私人视角 + 判断力 + 对立面承认 + 亲自下场 = 活人感的不可拆解

### 3 · 4 层自检体系（软件工程测试金字塔活人感版）

- **L1 硬性规则**（自动扫描）：禁用词 / 禁用标点 / 结构套话 / 空泛工具名 = 零命中
- **L2 风格一致性**（模式匹配）：开头 / 节奏 / 口语化 / 标点禁令 = 至少 3/4 通过
- **L3 内容质量**（深度审查）：观点支撑 / 知识输出方式 / 文化升维 / 对立面同理心 = 关键项全过
- **L4 活人感终审**（最终人格层）：温度 / 独特性 / 姿态 / 心流 = "这像是真人写的"

### 4 · 6 类绝对禁区（AI 味检测器）

套话 / 过度结构化 / 标点（冒号·破折号·双引号）/ 高频踩雷词（说白了·意味着什么·本质上·换句话说·不可否认）/ 假设性例子 / 空泛工具名 = 6 类禁区 = 100% AI 标志
