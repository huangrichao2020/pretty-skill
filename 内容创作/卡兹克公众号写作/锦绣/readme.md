## 导语（公众号开头 · 自媒体稿开头）

在 AI 写文章越来越普及的今天，为什么公众号上还是有人读完想用，有人读完就关？差别不在语法，不在排版，差在一个东西 —— 「活人感」。

今天给大家分享一套我从数字生命卡兹克那里学来的公众号长文方法论：5 种文章原型 + 7 大风格内核 + 4 层自检体系 + 6 类绝对禁区 + 5 种开头必杀技 + 5 种收尾。任何人按这套范式，都能写出"卡兹克级"活人感公众号长文。

> **核心要点**（AI 友好 · 1 屏可读）：
> - AI 能写出语法正确的文章，但写不出让人读完想用的文章
> - 卡兹克风格 = "有见识的普通人在认真聊一件打动他的事"
> - 5 种原型先判断再动笔 · 7 大风格内核不可拆解
> - 4 层自检体系 = 软件工程测试金字塔的活人感版本
> - 6 类绝对禁区 = AI 味检测器（套话 / 标点 / 高频踩雷词 / 假设性例子 / 空泛工具名）

## 第 1 章 · AI 代笔的 5 个隐藏陷阱

> **公众号正文 / 自媒体稿**：套话陷阱（"说白了""本质上"）一出现立刻暴露 AI 味。标点陷阱（冒号、破折号、双引号）是 AI 三大标志。教科书开头（"在当今 AI 快速发展的时代"）一秒劝退。空泛工具名（"AI 工具""某个模型"）证明你没真用过。假设性例子（"比如有一次..."）是大忌。一个活人的体感记忆，AI 永远学不来。
>
> **核心要点**：
> - 套话 / 标点 / 教科书开头 / 空泛工具名 / 假设性例子 = 5 大 AI 标志
> - 任一出现 = 暴露 · 全部出现 = 退稿

## 第 2 章 · 5 种文章原型

> **公众号正文 / 自媒体稿**：写之前先判断属于哪种原型，每种的写法重心完全不同。调查实验型（"我替你去做了这件事"）重心在过程叙事。产品体验型（"跟我一起玩"）重心在场景演示。现象解读型（"你注意到了吗？背后是什么？"）重心在观察→好奇→研究→升维。工具分享型（"我发现了一个好东西"）重心在故事铺垫→工具展示→效果惊艳。方法论分享型（"压箱底的东西掏给你了"）重心在每节有可执行动作 + 坦诚失败点。
>
> **核心要点**：
> - 先判断原型，再动笔 · 写错原型 = 写法全错
> - 5 种原型各有真实案例（买 9.9 DeepSeek / miclaw / AI 看不到爱心 / 天赋挖掘 Prompt / 用 AI 三年 9 条心得）
>

## 第 3 章 · 7 大风格内核

> **公众号正文 / 自媒体稿**：活人感 = 节奏 + 故意打破 + 知识"聊着聊着掏出来"+ 私人视角 + 判断力 + 对立面承认 + 亲自下场。节奏是跟朋友聊天不像写报告（长短句交替 + 一句话独立成段）。故意打破是重复强调、中途叹息、省略主语、刻意模糊。知识输出方式是"聊着聊着顺手掏出来"不是"下面我来给大家科普一下"。私人视角是用"我也面临这个问题"代替"这给我们的启示是"。判断力是敢下判断 + "我被打动了"姿态。对立面承认是先站到对方角度把对方处境具体化再切入自己视角。亲自下场是让读者感觉到"这个人真的做了这件事"。
>
> **核心要点**：
> - 7 大基因 + 11 大风格技巧（契诃夫之枪 / 升番逻辑 / 文化升维 / 读者直呼 / 疑问句节奏 / 层层剥开 / 英雄之旅 / 反向论证 / 谦逊铺垫 / 句式断裂 / 人物画像法）

## 第 4 章 · 6 类绝对禁区

> **公众号正文 / 自媒体稿**：6 类禁区 = 100% AI 标志 = 退稿。套话（"首先...其次...最后""综上所述""值得注意的是""不难发现""让我们来看看""接下来让我们"）。过度结构化（不用 bullet 罗列、不大量加粗、不加小标题除 N 条心得型）。标点禁令（不使用冒号、破折号、任何双引号）。高频踩雷词（"说白了""意味着什么？""这意味着""本质上""换句话说""不可否认"）。假设性例子（"比如有一次..."编造场景）。空泛工具名（不说"AI 工具""某个模型"·要说 Claude Code / Codex / Seedance 2.0）。

> - 6 类禁区 / 5 类禁用标点 / 6 个高频踩雷词

## 收尾 · 写得让人读完想用

公众号长文的目标不是写清楚，是让人读完想用。卡兹克风格的本质不是技巧，是活人感 —— 一个有见识的普通人在认真聊一件打动他的事。

下次动笔之前，先问自己三个问题：这篇文章属于哪种原型？我有没有真做过这件事？我有没有敢下判断？

写得让人想用，才算真的会。
