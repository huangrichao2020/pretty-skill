## 融合稿

```markdown
# 1 周做出像样的个人 IP 形象 + 表情包

你有没有过这种时刻：
- 写公众号，每次想配图都要去图库翻 30 分钟
- 写 PPT，每次画的"小人物"风格都不一样
- 想做表情包，发现画师报价 ¥3000+ 起

**问题不是"没审美"，是"没系统"**。

我用 1 周时间做出 Mavis 狐狸 IP 形象 + 14 张母版
（6 张处境 + 8 张情绪），全靠这套方法论：

## 5 要素设计哲学
1. **极简形象**（不是卖萌）
2. **承担核心动作**（不是装饰）
3. **真实物件**（不是抽象符号）
4. **大量留白**（不是满屏）
5. **空表情**（不是笑/哭/怒画脸上）

## 3 步流程
1. **调研**：找 1-2 个参考 IP，拆解 5 要素
2. **设计**：3-5 套形象候选 → 选 1 套
3. **母版化**：6 处境 + 8 情绪 = 14 张母版库

## 实战案例：Mavis 狐狸 IP
- 🦊 橙红 + 奶油色肚子 + 黑点眼 + 工具感
- 14 张母版：会议拉回 / 消息过载 / 生产报警 / 审查返工 / AI 自动化 / AI 简历 / 庆祝 / 崩溃 / 思考 / 尴尬 / 得意 / 愤怒 / 惊讶 / 暖心

## 7 天行动清单
- [ ] Day 1-2 调研
- [ ] Day 3 设计
- [ ] Day 4-5 处境母版
- [ ] Day 6-7 情绪母版
- [ ] 跑 3 个月实战 → 沉淀方法论

完整方法论 + prompt 模板见 pretty-skills 仓库。
```
