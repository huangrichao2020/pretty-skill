## 复用步骤

### 写自己的杂志风公众号（30 分钟）

1. **抄骨架**（5 分钟）：复制本 case 的 P0-P7 7 段骨架
2. **套钩子链**（10 分钟）：5 段叙事填入
   - 段 1 日常+反差
   - 段 2 按维度分类
   - 段 3 每类 1 段精炼
   - 段 4 共同痛点 = 加粗整句
   - 段 5 顺势不抢戏
3. **出 4 张图**（15 分钟）：
   - 必画 P0 + 1 张 P1 + 2 张 P5
   - 矩阵图优先（多宫格 + 黑底）

### 训练 AI 出图的 prompt 参考

- **多宫格**：8 主题 matrix，each with different color palette
- **黑底矩阵**：black background, 3D perspective, multiple PPT thumbnails
- **编辑器高亮**：white background content, blue dashed selection box, right panel
- **风格样图**：each scheme 1 representative image + theme name

## 反 AI 味 7 问自检

1. emoji 出现几次？0 = 通过
2. 段落最长几句？≤ 3 = 通过
3. 加粗整句 ≥ 1？= 通过
4. 配图 ≥ 4？= 通过
5. 有多宫格图？= 通过
6. 转折是加粗整句？= 通过
7. 标题有"反 AI 味"自检？= 通过
