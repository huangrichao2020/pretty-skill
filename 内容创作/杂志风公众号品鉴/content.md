## P3 · 排版规则 · 6 条铁律

- **标题**：排版 6 条铁律 · 0 emoji + 0 装饰 + 0 套话
- **副标**：删掉所有"看起来需要其实不需要的"
- **章节类型**：核心解法
- **核心主张**：排版极简 = 强制每个字都有信息量
- **认知锚点**：「删比加更重要」—— 1 段 200 字砍到 50 字 = 排版升级
- **关键要点**：
  - **规则 1 · 0 emoji**：emoji 不是装饰，是"我没想清楚"的外包
  - **规则 2 · 0 分割线**：段间空行就是分割线
  - **规则 3 · H2 + H3 二级**：不要 H1 大标题 + 序号小标题
  - **规则 4 · 1-3 句成段**：5 句以上立刻 break
  - **规则 5 · 加粗整句做转折**：不靠 bullet 转折，靠加粗整句
  - **规则 6 · 行内 code 用反引号**：`HTML` / `pptx` / `.css`
- **数据 / 数字**：6 规则 / 0 例外
- **金句**：排版不是"用好看字体"，是"让每个字都不可少"。

## P4 · 叙事规则 · 5 段钩子链

- **标题**：5 段钩子链 · 不抢戏的顺势推荐
- **副标**：日常 → 分类 → 痛点 → 顺势 → 不抢戏
- **章节类型**：核心解法
- **核心主张**：5 段钩子链 = 反 AI 味的标准叙事骨架
- **认知锚点**：「日常+反差 → 顺势不抢戏」—— 5 段就是 1 个闭环
- **关键要点**：
  - **第 1 段 · 日常 + 反差**："已经从噱头变成日常...但有一个共同的痛点"
  - **第 2 段 · 按维度分类**："按技术路线分 3 类"（HTML / PPTX / 桥梁）
  - **第 3 段 · 每类 1 段精炼**：3-4 句，含特征 + 风格 + 优缺点
  - **第 4 段 · 共同痛点 = 硬转折**：加粗整句"**生成很爽，改很崩溃**"
  - **第 5 段 · 顺势不抢戏**：自家方案定位"补另一环"，不跟生成派抢
- **数据 / 数字**：5 段 / 1 闭环 / 1 硬转折
- **金句**：好的钩子链 = 让读者觉得"我也这么想"再"原来是这样"。

### 5 段钩子链实战

```
段 1 日常+反差: "让 AI 帮我做 X，已经从噱头变成日常了。但有 1 个共同痛点。"
段 2 按维度分类: "我按'技术路线'分了三类。"
段 3 1 段精炼:   "**A** 是 X，**B** 是 Y，**C** 是 Z。" (3 工具 × 3-4 句)
段 4 硬转折:     "**生成的时候很爽，改的时候很崩溃。**" (加粗整句)
段 5 顺势:       "我不去凑这个热闹，去补另一环：让已生成的 X 可视化微调。"
```

## P5 · 配图规则 · 5 类必杀图

- **标题**：配图 5 类必杀图 · 多宫格 + 黑底 + 编辑器
- **副标**：1 张配图撑全场 = AI 味标志
- **章节类型**：核心解法
- **核心主张**：杂志风配图 = 矩阵对比 + 工具截图 + 极简高亮
- **认知锚点**：「多宫格 = 1 张顶 5 张」—— 对比产生冲击
- **关键要点**：
  - **类型 1 · 多宫格对比图**（6/9 宫格主题）：一次展示多种方案
  - **类型 2 · 黑底 3D 透视矩阵**：立体感 + 作品集冲击力
  - **类型 3 · 工具截图 + 极简高亮**：白底内容 + 1 个强调色（蓝虚线选中框）
  - **类型 4 · 风格主题样图**：每方案 1 张代表样图 + 主题名
  - **类型 5 · 右下角小水印**：品牌不抢戏
- **数据 / 数字**：5 类 / 0 类单张撑场 / 1 水印位置
- **金句**：配图不是"加张图"，是"用图制造冲击"。
