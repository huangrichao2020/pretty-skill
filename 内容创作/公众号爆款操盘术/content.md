# 公众号爆款操盘术 · 把方法论写成别人看完就想用

> 3F Content 范式 · F1 源文字版 · 公众号长文写作的可复用钩子工程

---

## P0 · 封面 / 定位

- **标题**：公众号爆款操盘术
- **副标**：把方法论写成别人看完就想用的东西
- **章节类型**：封面
- **核心主张**：公众号不是写文章，是做一场"让人想用"的阅读钩子工程
- **关键要点**：
  - 收藏即学会 = 幻觉，干货困在 PDF / PPT 里没人看
  - 好方法讲不清 = 负担，不是资产
  - 写作目标 = 让人看完想用，不是写清楚
- **数据 / 数字**：1 套 5 段钩子链
- **金句**：写得让人想用，才算真的会

---

## P1 · 痛点切入

- **标题**：用真痛点开场，别讲道理
- **副标**：痛点 > 道理，场景 > 概念
- **章节类型**：核心解法
- **核心主张**：开篇 200-300 字必须戳中一个真实可感知的困境
- **关键要点**：
  - 三个高频坑：干货困死在封闭格式 / 装 100 个 skill 互相打架 / 好方法讲不清
  - 用"你"开场，制造镜像焦虑（被未读文件淹没的画面）
  - 痛点要具体可感知，不空谈"知识焦虑"
- **数据 / 数字**：3 个真坑
- **金句**：读者只为自己的痛点停留

---

## P2 · 结构范式（5 段钩子链）

- **标题**：一次创作，多形态分发
- **副标**：痛点 → 翻转 → 范式 → 案例 → CTA
- **章节类型**：核心解法
- **核心主张**：任意方法论都能套 5 段链讲透
- **关键要点**：
  - 翻转定位：把一个旧认知推翻（"这里不是工具箱，是出版局"）
  - 范式落地：3F + 锦绣——写一次，网页 / PPT / 手机卡 / 视频全有
  - before / after 对比表压场，让人拿走就能用
- **数据 / 数字**：5 段链 / 4 形态
- **金句**：一个范式顶一百个技巧

---

## P3 · 风格纪律与发布

- **标题**：刘润式纪律 + 4 图闭环
- **副标**：简洁有观点，禁 emoji 禁话题标签
- **章节类型**：收束
- **核心主张**：风格纪律决定可信度，配图闭环决定完读
- **关键要点**：
  - 禁 emoji / 禁话题标签 / 禁"欢迎评论区"套话
  - 4 图闭环：封面 + 痛点图 + 范式图 + 案例花园图
  - 多端分发：公众号深度 / 小红书精简 / 飞书·知乎文档版
- **数据 / 数字**：4 图 / 3 端
- **金句**：克制比华丽更有力量
