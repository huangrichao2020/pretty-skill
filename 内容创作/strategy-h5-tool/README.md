## 核心洞察

**小工具的本质 = 知识的网页讲解版**

小红书上攻略、笔记、心得、游记最多，但有 3 个原生解决不了的痛：

1. **攻略太长** → 9 宫格讲不清 7 天行程
2. **心得太散** → 没法对比、没法锚定关键节点
3. **笔记太碎** → 看完不知道下一步做什么

小工具 = 9 宫格 + 单页短文的"升级形态"：
- 9 宫格是**折叠**（情绪/速览/种草，文字 ≤1000 字）
- 小工具是**展开**（结构/对比/流程，可承载多日多线）

→ 解决方案 = **双维选择（天数 × 节奏）+ 9 条攻略线 + 路径地图 + 风格色主题**

### 阶段 0 · 信号研究（发布前 1-2 周 / 换城市时）

**目标**：抓 10-20 条同题材高互动内容，提取可复用结构

**输入**：
- 目标城市 / 主题
- 平台范围（小红书 / 抖音 / 公众号）

**动作**：
1. 小红书首页推荐流前 10-20 条，**记录**：title / hook / angle / 结构标签 / 评论信号 / CTA / 标签组
2. 评论区抓两批（热门 Top10 + 最新 Top10）→ 抽取支持/反对/中性观点
3. 跨平台 web_search 综合 60+ 攻略 → 去广告 + 数据交叉

**输出**：
- 候选池 10-20 条
- 标题骨架 3-5 个（如「请按下确认键」「情绪词 + 具体对象」）
- 封面层级模板（主文案/副文案/字大/字小/色）

**工具**：
- `web_search`（百度/小红书搜索）
- 截图首页 + OCR（如果用浏览器）

**量化疗效**：1 个城市 30 分钟出信号池，vs 拍脑袋写

### 阶段 1 · 账号定位（首次 / 改方向时）

**目标**：4 变量锁账号骨架，所有内容不跑偏

**4 变量**：
| 变量 | 含义 | 杭州烟雨 v1 实例 |
|---|---|---|
| 目标用户 | 年龄 / 场景 / 痛点 | 周末 2-3 天出游 / 自由行 / 选节奏困难症 |
| 内容价值主张 | 每篇给用户什么 | 9 条现成攻略 + 路径地图，开包即用 |
| 差异化角度 | 同类账号不做什么、你做什么 | 双维选择（天数×节奏）笛卡尔积，不只做 1 套 |
| 风格规范 | 语气 / 长度 / 冲突边界 | 短句 + 数据 + 数字 + 不剧透（涉及隐私内容） |

**输出**：
- 人设关键词 3-5 个
- 内容支柱 3 个
- 口头禅/固定句式 2-3 个
- 红线清单（剧透 / 人身攻击 / 虚假承诺）

**工具**：persona.md 模板（xhs-ops 已沉淀）

### 阶段 2 · 选题评分（每次发布前）

**目标**：从"我有 10 个选题" → "这 3 个能发"

**5 维评分**（每维 0-2 分）：

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 热度信号 | 没数据 | 30+ 攻略提到 | 60+ 攻略 + 评论区争议 |
| 账号匹配 | 完全不沾边 | 部分匹配 | 完美匹配 4 变量 |
| 互动潜力 | 无互动钩子 | 1 个问句 | 站队 + 选择 + 经验 3 钩子 |
| 可写性 | 信息缺口大 | 1-2 个待查 | 全部现成 |
| 风险分 | 极高（必踩线）| 中等（可绕）| 低（安全）|

**总分规则**：
- ≥ 6 分：可发
- 7-8 分：强发
- ≥ 9 分：必爆（信号强 + 完美匹配）
- 风险分 ≥ 2：直接淘汰

**杭州烟雨 v1 实战回填**：
- 选题"小工具内测第一天" = 蹭热点（星爷路演）+ 稀缺感（第一款攻略 H5）+ CTA（一键三连）
- 评分：热度 2 / 匹配 2 / 互动 2 / 可写 2 / 风险 0 = **8 分（强发）**

### 阶段 3 · 视觉包装（结合 v1 H5 6 步）

**目标**：封面 + 配图 + 路径 + 主题色，1 个动作不漏

**4 子任务**：
1. **封面**：主文案 + 副文案 + 1 条生图 prompt（高文字可读）
2. **配图**：3-6 张图解文案 + 对应 prompt
3. **路径地图**：AI 真实地理底图 + 绝对定位圆点 + SVG 贝塞尔曲线
4. **风格色主题**：CSS 变量 + body[data-style] 联动全站

**杭州烟雨 v1 实战数据**：
- 9 张景点（matrix 16:9）+ 1 张水墨底图 + 1 张雷峰塔 logo
- 路径 11 个 POI × 3 节奏颜色 = 33 个绝对定位点
- 14px 白边 + 7px 彩色双层描边
- 2.5s 描边 + 1.5s 虚线流动 + 8px 光点

### 阶段 4 · 评分检查（发布前 30 分钟）

**目标**：5 维度体检，少 1 分都不发

**5 维度**：
| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 定位 | 跟账号方向不沾 | 部分沾 | 完全匹配 4 变量 |
| 结构 | 标题/封面/正文错位 | 1 处错位 | 全对位 |
| 转化 | 无 CTA / CTA 模糊 | 1 个清晰 CTA | CTA + 互动问句 + 标签 |
| 辨识度 | 像 100 篇同质笔记 | 有 1 个记忆点 | 标题+封面+正文 3 个记忆点 |
| 可持续 | 一次性 | 可延展 1 篇 | 可延展系列（3 篇+）|

**总分 8+ 才发**，< 8 分回炉重做

## 6 步制作工作流（v1 保留）

```
1. 调研    →  小红书 + 站外 60+ 篇攻略综合（去广告 + 数据交叉）
2. 矩阵    →  N 天 × 3 节奏 = 9 条攻略线（每条带步数/预算/适合人群）
3. 配图    →  9 张景点 + 1 张地图底图 + 1 张 logo（matrix 生图 · 水墨风）
4. H5 编码 →  交互骨架 + 动效 + 风格色主题（CSS 变量联动）
5. 校验    →  minitool-zip-builder SKILL.md 自检（无内联/无外链/单图 < 500KB）
6. 打包    →  zip 上传小红书 / 真机 WebView
```

## 3 档节奏（核心差异化）

| 节奏 | 步数/天 | 日均预算 | 关键词 |
|---|---|---|---|
| 🟠 特种兵 | 2.5-3.5 万 | ¥300-400 | 日行 3 万步、地铁+单车、不进茶馆 |
| 🟢 正常 | 1.5-2 万 | ¥500-600 | 8 点起、1 次船游 + 1 次登塔、节奏均匀 |
| 🔵 休闲 | 0.6-1.2 万 | ¥900-1500 | 9 点后、骑行+徒步、必含 1 次茶馆 2h+ |

## 7 大技术要点

1. **双维 tab 选择**（天数 × 节奏 = 9 组合）— 6 个 tab + 风格色联动
2. **CSS 变量主题切换** — `body[data-style]` 改 `--style-color`，所有元素跟着变
3. **AI 底图 + overlay 路径** — 1 张水墨底图 + 绝对定位圆点 + SVG 路径叠加
4. **贝塞尔曲线动效** — 2.5s 描边 + 1.5s 虚线流动 + 光点跑动
5. **预算滑块计算器** — 3 档住宿 × 日预算 × 风格系数 = 实时总预算
6. **风格色主题联动** — banner / 路径 / 时间轴 / 数字色全部跟着切
7. **小红书打包校验** — minitool-zip-builder SKILL.md 全 14 条自检

## 反模式

**v2 新增**：
- ❌ 跳过阶段 0 直接做 → 没有信号池，标题凭感觉 → 评分 ≤ 6 必废
- ❌ 阶段 2 评分 < 6 还硬发 → 数据反馈差还不知道为什么
- ❌ 阶段 4 评分 8 分以下还发 → 漏 1 个维度，评论区冷场
- ❌ 阶段 5 自检流于形式 → 技术侧出问题，发出去打不开
- ❌ 不写 knowledge-base → 下个城市从头摸索，30 分钟变 3 小时

**v1 保留**：
- ❌ 用 SVG 画底图（用户反馈太素）→ 用 AI 出图
- ❌ 路径只画一次（粗）→ 双层描边 + 虚线 + 光点
- ❌ 单一风格色 → 必须 3 档主题色，元素全部 CSS 变量联动
- ❌ 9 宫格照搬笔记 → 改造成可交互 HTML
- ❌ 资源用 picsum/unsplash → 国内不稳，AI 生图本地化
