## P1 · 痛点切入

- **标题**：为什么"knowhub 方法论"沉淀后没人看
- **副标**：方法论 vs 可发内容
- **章节类型**：核心解法
- **核心主张**：90% 的方法论沉淀停留在 PDF/MD 形态，**没翻译成可发的内容**——本 skill 就是这个翻译层
- **认知锚点**：「方法论 → 内容的 4 大翻译坑」

```text
坑 1：硬搬照抄
  表现：把方法论的术语 / 长句直接念出来
  解决：9 模板把方法论"翻译"成口语化口播

坑 2：账号错位
  表现：情感号讲 Agent 知识 / 交易号讲情感分析
  解决：3 账号自动识别 + 路由

坑 3：平台不匹配
  表现：抖音内容发公众号 / 小红书内容发抖音
  解决：5 平台自动适配（封面/时长/比例）

坑 4：单形态产出
  表现：只给口播稿，没封面提示词 / 配图 / 多平台包
  解决：完整发布包（口播 + 封面 prompt + 配图 + 多平台版本）
```

- **数据 / 数字**：4 翻译坑 / 90% 沉淀后没人看
- **金句**：方法论不变成内容 = 自己感动自己

## P2 · 9 模板 × 3 账号

- **标题**：3 账号 × 3 模板 = 9 种内容形态
- **副标**：按账号自动匹配模板
- **章节类型**：核心解法
- **核心主张**：本 skill 把"情感 / Agent / 交易" 3 大账号拆成 9 种内容模板，按用户关键词自动识别账号 + 路由到对应模板
- **认知锚点**：「9 模板路由」

```text
情感关系号（emotional-relationship）
  A 江湖观点体  800-1200 字 / 深度拆解（破执念开头 + 场景 + 机制 + 死循环 + 突破 + 金句）
  B 金句+案例+行动体  300-500 字 / 短平快（金句 + 小案例 + 底层机制 + 一步行动）
  C 情绪翻译体  200-300 字 / 翻译一句话的真意（原话 + 翻译 + 场景 + 行动）

定制 Agent 号（ai-agent）
  D 每日 AI 实践体  400-600 字（今天用 AI 做了什么 + 怎么做的 + 收获）
  E 架构知识科普体  600-800 字（概念 + 原理 + 案例 + 应用）
  F 工具测评体  400-600 字（工具 + 优点 + 缺点 + 推荐场景）

股市交易号（trading-review）
  G 每日复盘体  400-600 字（今日盘面 + 关键数据 + 解读 + 明日关注）
  H 错误模式拆解体  500-700 字（错例 + 错因 + 正确做法 + 复盘）
  I 盘面诊断体  300-500 字（一句话定调 + 关键信号 + 操作建议）
```

- **关键要点**：
  - 账号识别：用户关键词 → 自动匹配
    - 情感：情感 / 关系 / 亲密 / 执念 / 信号 / 体面 / 吸引 / 边界
    - Agent：Agent / AI / MCP / 技能 / skill / 自动化 / 效率
    - 交易：交易 / 复盘 / 大盘 / 涨停 / 情绪 / 纪律 / 亏损
  - 无法识别时问用户："这是给哪个号做的内容？"
  - 模板可组合（A+C 金句情绪翻译 + 长短配）
- **数据 / 数字**：3 账号 / 9 模板 / 路由关键词各 8 个
- **金句**：账号错位 = 流量浪费

## P3 · 多平台适配 + 视频生产工具栈

- **标题**：5 平台 × 3 视频工具栈
- **副标**：1 套口播稿，5 个平台版本
- **章节类型**：核心解法
- **核心主张**：1 套口播稿要适配 5 个平台（封面尺寸 / 视频比例 / 时长 / 标题风格），并用对应工具栈生产
- **认知锚点**：「5 平台 + 3 工具栈」

```text
5 平台适配
  抖音     9:16 / 30-60s / 强钩子开头 / 文字大字
  小红书   3:4 / 30-60s 或图文 / 标题党 + emoji
  B 站     16:9 / 3-10min / 深度讲解 / 弹幕友好
  公众号   1:1 / 图文 / 长文 / 标题党
  视频号   9:16 或 1:1 / 30-90s / 微信生态

3 视频生产工具栈
  知识讲解动画  Remotion 主线 + Manim 辅助（动画 + 数据可视化）
  小红书风格 HTML  自建 HTML/GSAP 组件库 + html-video 快速验证
  个人口播剪辑  WhisperX（转字幕）+ auto-editor（自动剪辑）+ LosslessCut（精修）
```

- **关键要点**：
  - 1 套口播稿 → 必须输出 5 平台版本（封面 + 视频 + 标题 + 简介）
  - 工具栈按内容类型选，不是按平台选
  - 知识讲解 → Remotion；图文 → HTML/GSAP；口播 → WhisperX + auto-editor
  - 默认推荐：知识讲解动画用 Remotion（最稳）
- **数据 / 数字**：5 平台 / 3 工具栈 / 1 稿 5 用
- **金句**：1 稿 5 用 = 5 倍流量

## P4 · 完整发布包

- **标题**：1 套口播稿 = 5 大产物
- **副标**：口播 + 封面 + 配图 + 标题 + 简介
- **章节类型**：核心解法
- **核心主张**：完整发布包 = 5 大产物（口播稿 / 封面 prompt / 配图 prompt / 平台标题 / 平台简介），不只给口播稿
- **认知锚点**：「5 大产物」

```text
发布包 5 大产物
  1 口播稿
     内容（按 9 模板之一）
     字数（按平台）
     节奏（关键打击单独成段）
  2 封面 prompt
     画面描述（具体可出图）
     风格（手绘 / 商务 / 杂志风）
     文字（3-8 字标题）
  3 配图 prompt
     平台比例（抖音 9:16 / 小红书 3:4 / B 站 16:9）
     风格统一
     多图叙事（1 套 3-9 张）
  4 平台标题
     抖音：强钩子（疑问 / 数字 / 反差）
     小红书：标题党 + emoji
     B 站：好奇心 + 知识感
     公众号：信息密度高
  5 平台简介
     引导评论 / 引导关注 / 引导加群
```

- **关键要点**：
  - 5 大产物缺一不可：只给口播稿 = 半成品
  - 封面 prompt 必须可出图（具体到画面 + 风格 + 文字）
  - 配图多图叙事：1 套 3-9 张 = 平台停留时长
  - 标题和简介：不同平台不同风格（不能通用）
- **数据 / 数字**：5 大产物 / 1 稿 5 用
- **金句**：5 产物齐全 = 平台算法优先

- **标题**：默认"翻译层"模式 · 触什么走什么
- **副标**：拿来即用
- **章节类型**：收束

- **认知锚点**：「3 步翻译」

```text
3 步翻译 SOP
  Step 1 账号识别：用户关键词 → 3 账号之一
  Step 2 模板匹配：账号 → 9 模板之一
  Step 3 平台适配：模板 → 5 平台 × 5 大产物

素材路径（按账号路由到 knowhub 域）
  情感号 → knowhub/domains/emotional-relationship
  Agent 号 → knowhub/domains/ai-agent
  交易号 → knowhub/domains/trading-review

视频生产工具栈
  知识讲解 → Remotion + Manim
  小红书 HTML → HTML/GSAP 组件库 + html-video
  口播剪辑 → WhisperX + auto-editor + LosslessCut

输出 5 大产物
  口播稿 / 封面 prompt / 配图 prompt / 平台标题 / 平台简介
```

- **关键要点**：
  - 与 pretty-skills 内容创作 15 case 互补：本 case 是"翻译层"，其他是"创作 SOP"

  - 触什么走什么，不一次加载全部 9 模板
- **数据 / 数字**：3 步 / 9 模板 / 5 平台 / 5 产物
