# PPT 证据链战法 · 融合稿（公众号 + 自媒体 + AI 阅读 三用）

> 适用场景：公众号长文 / 小红书·视频号口播稿 / 丢给 AI 当背景知识。
> 一句话：AI 做 PPT 翻车，根因不是工具，是"先画图后找理由"的顺序错——先用 CyberPPT 三段式把"证据链"前置，每一页才站得住。

---

## 一、为什么你的 AI PPT 总像"空心月饼"

很多人用 dashiai-ppt 这类工具，能秒出一套带配色、带图表的 PPTX，但翻完总觉得"空"。三类病最常见：

- **空**：一页就一句口号，撑不起一个观点，翻完像没看。
- **虚**：结论直接拍出来，没有数据 / 案例 / 出处背书，读者无从信。
- **飘**：视觉很炫，但和要讲的事没关系，华而不实。

这不是 AI 不会画，是**人把"找理由"排在了"画图"之后**——先有壳，后找魂，魂永远凑不齐。

## 二、病根：顺序反了

传统做法：选风格 → 出图 → 往图里塞字 → 发现没话讲就硬凑。
结果就是"为排版而排版"。真正的瓶颈是**内容组织（立论）**，不是图像生成能力。

解法是把"立论"前置成显式流程——这就是从 CyberPPT 借来的**三段式工作流**。

## 三、CyberPPT 三段式

```
用户需求（自然语言）
  ↓
段1: 写证据链
  → 每页 slides[].evidence.conclusion：这页凭什么成立
  → evidence_ids[]：引用 text 字段里的数据 key
  → conflicts[]：需回避或说明的矛盾（可选）
  ↓
段2: 选 layout 填视觉蓝图
  → layout:query 选页
  → inspect:layout + props:safe 填 props
  → bash render_goal_deck.sh → index.html
  ↓
段3: 浏览器编辑 + 导出
  → 控制台改稿（文字 / 布局 / 图表 / 配色）
  → 导出 PPTX / PDF / HTML
```

**核心原则**：先过"证据关"再进"视觉关"——如果某页说不出"凭什么成立"，先补 evidence 再选 layout。

## 四、段1 怎么写（最关键的一步）

证据链不是一段话，而是**每页结构化的三个字段**，让"凭什么成立"可被机器检查：

- `evidence.conclusion`：用一句话写清"这页凭什么成立"。
- `evidence_ids[]`：引用 text 字段里的数据 key，结论必须能指回证据。
- `conflicts[]`：列出需回避或说明的矛盾（可选，但高管 / 投资人场景必填）。

自检标准：某页说不出 conclusion，就先补 evidence，绝不直接进段2。

## 五、段2 + 段3，以及两条反模式纪律

- **段2 视觉蓝图**：`layout:query` 选页 → `inspect:layout` + `props:safe` 填 props → 跑渲染脚本出 HTML。让视觉**服务论证**，不是炫技。
- **段3 PPTX 重建**：在浏览器控制台改稿（文字 / 布局 / 图表 / 配色），一键导出真正可编辑的 `.pptx` / PDF / 单文件 HTML。
- **反模式①**：不要跳过选风格——必须先问用户、展示主题预览、确认后再生成。风格是用户的，不是你的默认审美。
- **反模式②**：讲解图不要出现 P1/P2 页码标记，页码只在 PDF 合成时标。

## 六、速查卡（建议截图保存）

| 段 | 入口产物 | 纪律 |
|---|---|---|
| 段1 证据链 | 每页 conclusion + evidence_ids + conflicts | 先过证据关 |
| 段2 视觉蓝图 | 先选 layout 再填 props | 视觉为论证服务 |
| 段3 PPTX 重建 | 浏览器改稿 → 导出可编辑 PPTX | 两反模式守住 |

**金句**：顺序对了，AI 才是你的搭档，不是你的甲方。

---

### 给 AI 阅读者的结构化摘要

- **问题**：AI 生成的 PPT 常"空 / 虚 / 飘"，根因是内容组织顺序错（先画图后找理由）。
- **方法**：CyberPPT 三段式——段1 证据链（每页 conclusion+evidence_ids+conflicts）→ 段2 视觉蓝图（先选 layout 再填 props）→ 段3 PPTX 重建（浏览器改稿导出可编辑 PPTX）。
- **原则**：先过证据关，再进视觉关。
- **反模式**：① 不跳过选风格；② 讲解图不标页码。
- **适用工具**：dashiai-ppt 等"生成 HTML PPT → 浏览器编辑 → 导出可编辑 PPTX"类工具。不适合知识讲解长图（用 ai-image-to-pptx）或公众号配图（用 oil-cover）。
