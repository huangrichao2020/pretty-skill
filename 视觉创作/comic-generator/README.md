# comic-generator · 文字故事转漫画

> **一句话定位**：文字故事自动拆分为分镜 + 漫画风格面板 + 合成完整漫画页面

---

## 这个 case 是什么

**页数**：4 页 · **领域**：视觉创作

## 核心论点

故事不该只有文字 · comic-generator = 自动分镜拆解（场景/人物/动作/旁白/对白）+ 跨图角色一致 + 完整漫画页面合成。

## 4 步工作流

1. 故事输入（用户上传故事文本或描述）
2. 分镜拆解（自动：场景/人物/动作/旁白/对白）
3. 面板生成（每格单独生图 · 风格统一）
4. 合成为页面（拼成完整漫画页 · 16:9 / 9:16）

## 关键能力

- 自动分镜拆解
- 漫画风格面板（多风格：日漫/美漫/港漫/简笔/黑白线稿）
- 跨图角色一致性（基于参考图）
- 完整漫画页面合成

## 适用场景

- 用户上传故事文本
- 描述想要视觉化呈现
- 真人/小说/剧本 → 漫画
