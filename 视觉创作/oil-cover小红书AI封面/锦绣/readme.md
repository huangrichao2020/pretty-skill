## 导语（公众号开头 · 自媒体稿开头）

做小红书 AI 工具内容的同学都懂一件事 —— 封面 = 流量入口。一条工具教程做得再好，封面不行，用户划走，等于白做。

今天给大家分享一套我从 oil 欧呦老师那里学来的小红书 AI 工具封面方法论：5 大方法论支柱 + 2 种执行模式 + 12 项必填件 + 完整 SOP · 让你每次出封面都稳定、清楚、干净、精致、一次成图。

> **核心要点**（AI 友好 · 1 屏可读）：
> - 5 大支柱：稳定 + 清楚 + 干净 + 精致 + 一次成图 = 缺一不可
> - 2 种模式：脚本模式（默认）vs Agent 自主执行模式 = 一次性设好
> - 12 项必填件：触发 / 一次成图 / 内容干净 / 默认输出 / 资产保存 / 安全
> - 默认入口：4 个参数搞定 90% 场景 · 默认并行生成 3:4 + 4:3

## 第 1 章 · 小红书 AI 工具封面的 5 大难题

> **公众号正文 / 自媒体稿**：AI 工具封面需要真实屏幕证据 + 干净风格 + 一次成图 · 90% 的自动封面做不到。难题 1：AI 编造虚假界面截图 = 用户一眼识破。难题 2：文字 + Logo 后贴到画面 = 廉价拼贴感。难题 3：保留人物头像 / 真人画中画 = 工具类封面失焦。难题 4：套用上一次任务的产品名 / 关键词 = 翻车。难题 5：选帧瞎选（盲采等距帧）= 没抓到最能展示工具的瞬间。一次成图，胜过十次拼贴。

## 第 3 章 · 两种执行模式 + 持久化选择

> **公众号正文 / 自媒体稿**：脚本模式（默认）= generate_oil_cover.py + ZenMux Gemini 选帧 + gpt-image-2 生图 · 需要 Python + ffmpeg + ZenMux key。Agent 自主执行模式 = 自身多模态视觉选帧 + 自带 image_gen 工具 · 无外部依赖。模式选择存 `~/.oil-cover/config.json` 的 `mode` 字段 · **设一次，以后不问**。agent-native 失败回退：去 Codex 跑 · 或临时回退 script · 不要静默失败。
