## P1 · 痛点 · 小红书 AI 工具封面的 5 大难题

- **章节类型**：钩子
- **核心主张**：AI 工具封面需要真实屏幕证据 + 干净风格 + 一次成图 = 90% 的自动封面做不到
- **关键要点**：
  - 难题 1：AI 编造虚假界面截图 = 用户一眼识破
  - 难题 2：文字 + Logo 后贴到画面 = 廉价拼贴感
  - 难题 3：保留人物头像 / 真人画中画 = 工具类封面失焦
  - 难题 4：套用上一次任务的产品名 / 关键词 = 翻车
  - 难题 5：选帧瞎选（盲采等距帧）= 没抓到最能展示工具的瞬间
- **数据 / 数字**：5 大难题
- **金句**：一次成图，胜过十次拼贴

## P3 · 两种执行模式 + 持久化选择

- **章节类型**：核心解法
- **核心主张**：脚本模式（默认）vs Agent 自主执行模式 = 一次性设好不重复问
- **关键要点**：
  - **模式一 · 脚本模式**（默认）：generate_oil_cover.py · ZenMux Gemini 选帧 + gpt-image-2 生图 · 需要 Python + ffmpeg + ZenMux key
  - **模式二 · Agent 自主执行**：自身多模态视觉选帧 + 自带 image_gen 工具 · 无外部依赖
  - 模式选择存 `~/.oil-cover/config.json` 的 `mode` 字段（script / agent-native）
  - 第一次询问 · 设好之后不重复问 · 用户随时说"切换 / 改成 X 模式"覆盖
  - agent-native 失败回退：去 Codex 跑 · 或临时回退 script · 不要静默失败
- **数据 / 数字**：2 种模式 / 1 个 config 文件
- **金句**：设一次，以后不问

## P4 · 默认入口 + 进阶参数（脚本模式）

- **章节类型**：深化
- **核心主张**：默认 4 个参数搞定 90% 场景 · 进阶参数覆盖特殊需求
- **关键要点**：
  - 默认入口：video + title + topic · 截图/关键帧用 --image · Logo 用 --logo
  - 默认不传 --aspect = 并行生成 3:4 + 4:3 · 单独重跑用 --aspect 3x4 或 4x3
  - 取帧策略 --frame-select video（默认 · 让模型看视频选帧）/ sample（回退 · 均匀盲采）
  - --candidate-seconds 1,8,24.5：手动指定关键帧时间点
  - --subtitle：传字幕/文稿给 Gemini 帮助判断主题
  - --dry-run / --skip-generate / --generation-only：调试模式
- **数据 / 数字**：4 个默认参数 + 6 个进阶参数
- **金句**：默认参数不传 = 90% 场景的最佳实践
