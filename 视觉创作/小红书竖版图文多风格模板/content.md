## P1 · 痛点 · 5 大难题

- **标题**：小红书访谈图文的 5 大难题
- **副标**：风格 / 字体 / 排版 / 数据 / 一致性
- **章节类型**：钩子
- **核心主张**：90% 的访谈图文做得"看起来不像访谈"—— 缺固定骨架
- **关键要点**：
  - 难题 1：每张图 1 个风格（19 张图 = 19 个设计师）
  - 难题 2：字体版权（商用字体被告）
  - 难题 3：排版松散（标题/正文/数据卡没层级）
  - 难题 4：数据无处放（200 元 / 5000 元只能塞正文）
  - 难题 5：跨图不一致（封面是 1 调性，正文变另 1 调性）

## P3 · 调研 · 7 段骨架拆解

- **标题**：7 段骨架（必填 · 缺一不可）
- **副标**：页眉 → 章节号 → 标题 → 正文 → 金句 → 数据卡 → 页脚
- **章节类型**：调研
- **核心主张**：7 段是访谈图文的最小完整单元
- **关键要点**：
  - 段 1 · 页眉：栏目 logo（左右双头像 + 栏目名 + 受访者 + "访谈" 标签）
  - 段 2 · 章节号：`01 / 章节主题`（两位数 + 主题，4-8 字）
  - 段 3 · 主标题：一句话问题（带 `？` 钩子，60-80pt 粗体）
  - 段 4 · 正文：2-4 段，每段 1-2 行（30-40pt）
  - 段 5 · 金句：中部 `▕` 引线 + 加粗（视觉锚点 / 必填）
  - 段 6 · 数据卡：3 个等宽卡片 + 品牌色大字 + 灰色小字（可选）
  - 段 7 · 页脚：栏目 logo + 主题路径（5-7 个关键词）

## P4 · 写作 · 数据卡 3 联 · 视觉收口

- **标题**：数据卡 3 联 = 1 张图的视觉收口
- **副标**：3 个数字 / 3 个动作 / 3 个概念
- **章节类型**：写作
- **认知锚点**：「3 联 = 视觉收口」—— 让读者扫到图最后还能抓 3 个数据
- **关键要点**：
  - 卡 1 · 数字型：`200 元` + `单次远程安装`
  - 卡 2 · 数字型：`5000 元` + `安装服务收入`
  - 卡 3 · 概念型：`需求验证` + `先服务，再产品`
  - 卡片宽：`width: 30% · gap: 12px`（3 联等宽 + 中间留白）
  - 卡片底：品牌色 accent 10% 透明度
  - 数字字号：36-48pt 粗体 · 注释字号：14-16pt 常规

## P5 · 出图 · HTML 模板 + 5 套 CSS 变量

- **标题**：HTML 模板 · 5 套 CSS 变量
- **副标**：1 份 HTML 走 5 种风格
- **章节类型**：出图
- **认知锚点**：「CSS 变量 = 模板复用最简方式」
- **关键要点**：
  - 文件结构：`templates/base.html`（骨架）+ `templates/themes/{black-gold|sun-orange|forest-green|warning-red|tech-purple}.css`（5 套）
  - 切换方式：HTML 头部 `<html data-theme="black-gold">` 1 行切换
  - 输出方式：浏览器截图 / Puppeteer / html2canvas → PNG
  - 必填字段：`栏目名 / 编号 / 章节主题 / 主标题 / 4 段正文 / 1 句金句 / 3 个数据卡 / 页脚路径`
