## 5 套配色

| 风格 | 主色 | 调性 | 适用 |
|---|---|---|---|
| **黑金** | #000 + #d4a857 | 高端访谈 | 造物者说 / 创始人 / 投资人 |
| **橙白灰** | #fff + #f59e0b | 阳光日常 | 生活家 / Vlog / 旅行 |

| **紫蓝白** | #f5f3ff + #6366f1 | 科技 / AI | AI / 工具 / 测评 |

## 7 段骨架

- **页眉**：左侧栏目 logo · 右侧受访者 logo（左右头像 + 栏目名）
- **章节号**：黄色/品牌色小字 `01 / 章节主题`（两位数编号）
- **主标题**：白色/深色粗体 60-80pt，一句话问题（带 `？` 钩子）
- **正文**：30-40pt，2-4 段，每段 1-2 行，行距松
- **金句**：中部 `▕` 引线 + 加粗（视觉锚点）
- **数据卡**：3 个等宽卡片 + 品牌色大字数字 + 灰色小字注释
- **页脚**：栏目 logo + 主题路径（如 `起源 / 构建 / 增长 / 复盘 / 建议`）
