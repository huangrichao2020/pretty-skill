## 7 段骨架（不变 · 5 套主题共用）

- **页眉**：左侧栏目 logo · 右侧受访者 logo（左右头像 + 栏目名）
- **章节号**：`01 / 章节主题`（两位数编号 + 章节主题）
- **主标题**：粗体 60-80pt，一句话问题（带 `？` 钩子）
- **正文**：30-40pt，2-4 段，每段 1-2 行
- **金句**：中部 `▕` 引线 + 加粗（视觉锚点）
- **数据卡**：3 个等宽卡片 + 品牌色大字 + 灰色小字
- **页脚**：栏目 logo + 主题路径
