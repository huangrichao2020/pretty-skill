## 核心方法论

### 1 · 触发场景
- "做视频" / "知识讲解视频" / "动画讲解" / "React 写视频"

### 2 · 4 项核心能力
- Remotion（React 视频框架）编程
- 卡脖子讲解视频模板
- 每日机会扫描视频模板

设计视频脚本 → 拆解成 React 组件 → 用 Remotion 组合 → 导出视频
