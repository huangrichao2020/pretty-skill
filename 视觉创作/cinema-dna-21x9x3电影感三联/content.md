## P0 · 封面

- **核心主张**：电影感不是滤镜，是 4 个判断（镜头 / 光线 / 空间 / 叙事）先成立
- **认知锚点**：「先判断，再生成」 — 不堆提示词，5 步任务分析（任务→镜头→光线→空间→叙事）→ 才出图
- **疗效**：1 个主题 → 30 min 出 3 张 21:9 电影感三联图（建立世界 / 建立关系 / 留下余韵）
- **金句**：真正决定画面像不像电影的，不是滤镜，是镜头为什么成立。
- **配套图**：`hotel-pink-ritual-triptych.png` · 仪式感开场 · cinema-dna 经典示例

## P1 · 三镜头叙事合同（核心）

- **标题**：3 镜头叙事合同（v3 硬规则）
- **副标**：每镜头功能不同 + 至少 4 维变化
- **章节类型**：方法
- **核心主张**：3 镜头不是"换 3 个角度"，是"建立世界 / 建立关系 / 留下余韵" 3 个独立功能
- **关键要点**：
  - **Shot 1 建立世界**：24-28mm 焦段 · 中深景深 · 人物 5-15% 占比 · 环境信息 > 人物信息 · 像开场镜头
  - **Shot 2 建立关系**：32-50mm 焦段 · 人物 20-35% 占比 · 推进事件（接近/递交/发现/观察/等待/眼神接触）
  - **Shot 3 留下余韵**：50-85mm 或大广角 · 信息减少 · 背影 / 反射 / 局部身体 / 手势 / 空房间 / 半开门 / 留下的物件 / 远去的身影 · 未完成感
  - **去重复铁律**：3 张不能是同机位同姿势，必须至少 4 维变化（机位/前景/信息密度/光线/构图骨架/主体环境比/情感密度）
  - **禁用**：3 张同 wide shot、3 张人物都站着、3 张完整正面空间、重复构图骨架
- **数据/数字**：5 维差异 / 3 焦段梯度 / 至少 4 维变化
- **金句**：3 镜头不是 3 角度，是 3 个故事阶段。

## P2 · 现场摄影语言

- **标题**：现场摄影语言（On-Site Camera Language）
- **副标**：每镜头定 5+ 摄影参数
- **章节类型**：方法
- **核心主张**：每镜头必须把相机"放"在场景里，不是悬浮的"电影感"
- **关键要点**：
  - **必填 5+ 摄影参数**：
    - 焦段（focal length）
    - 机位高（camera height）
    - 相机-主体距离（camera-to-subject distance）
    - 主体在画面比例（subject frame percentage）
    - 前景遮挡（有/无）
    - 主空间轴（main spatial axis）
    - 光源（light source）
    - 焦点（focus point）
    - 角色视线（character sightline）
    - 关键信息位置（前景/中景/背景）
  - **21:9 横向关系**：左右对比、负空间、off-screen 延伸 — 不能简单宽裁剪
  - **构图铁律**：至少 3 个镜头含"门/玻璃/柱/栏杆/窗帘/家具/人群/窗户"作前景框
- **数据/数字**：10 摄影参数 / 至少 5 必填
- **金句**：相机在场景里，不是滤镜在 prompt 里。

## P3 · Anti-AI 电影画面纪律

- **标题**：Anti-AI 电影画面纪律（v4 规则）
- **副标**：画面像"抓拍的电影帧"不像"展示 prompt 的图"
- **章节类型**：方法
- **核心主张**：1 个主要故事线索 + 1 个次要线索 + 其余可以"无聊/暗/软/遮挡/空"
- **关键要点**：
  - **故事线索上限**：每镜头 ≤ 2-3 个具体场景细节 + 相机位 + 光源
  - **禁用词清单**：`rich detail` / `highly detailed` / `intricate` / `epic` / `dramatic` / `volumetric` / `beautiful` / `masterpiece` — 这些是 AI 提示词套语
  - **拒绝元素**：装饰性杂物 / 无处不在的烟雾 / 均匀锐度 / 高光 / 湿润表面 / 过度设计的道具
  - **优先元素**：日常实用地点 + 人性化时间节奏（等待/错过/半转身/离开/犹豫/隔玻璃看/迟到）
  - **明亮主体抗漂移**：蓝天/草地/青春/校园/阳光/干净红白色建筑/积极主体 — 必须保持"实拍电影帧"风格，不能变成动画/漫画/甜蜜商业/校招/偶像海报/旅行广告
- **数据/数字**：禁用 8 词 / 上限 2-3 场景细节
- **金句**：镜头成立的原因 = 5 摄影参数 + 1 故事线索 + 0 装饰。

## P4 · 光学缺陷 + 受控 dirt

- **标题**：光学缺陷 + 受控 dirt
- **副标**：每张选 1 种胶片介质 + 1 种 dirt 家族
- **章节类型**：方法
- **核心主张**：电影感来自光学真实感（胶片介质 + 受控瑕疵）
- **关键要点**：
  - **胶片介质 7 选 1**：
    - 35mm 发行拷贝（soft gate, print density, 细腻颗粒）
    - 16mm 电视转印（更软、块状颗粒、轻微色彩渗）
    - VHS / 老广播（luma noise, color bleed, 不稳定黑位）
    - MiniDV / 早期数码（小传感器实用光、动态范围有限）
    - 监控 / CRT / 监视器翻拍（几何失真、屏幕纹理、眩光）
    - 长焦胶片压缩（轻微浅景深、压缩人物、空气/热浪失真）
    - 广角 / 鱼眼见证者视角（车/门/人群/检查站/储物间/走廊/藏身处）
  - **Dirt 家族 7 选 1**：
    - 灰尘和干划痕 / 雨和湿润反射 / 烟雾和低功率灯 / 荧光机构污垢 / 广播/视频噪点 / 起雾玻璃或凝露 / 褪色织物和剥落油漆
  - **铁律**：不要在 1 帧里组合所有 dirt 模式
  - **镜头缺陷范围**：高对比边缘 / 高光 / 灯玻璃 / 窗框 / 建筑边缘 / 剪影 / 湿润反射 / 金属边缘 — 局部受控
  - **禁止**：cyber RGB split 等卡通失真
- **数据/数字**：7 胶片 / 7 dirt
- **金句**：每张选 1 胶片 + 1 dirt，不要 7 种全堆。

## P5 · Triptych 节奏（21:9 × 3）

- **标题**：Triptych 节奏（21:9 × 3 拼接）
- **副标**：3 张比例可非均分，黑白间隔作剪辑节奏
- **章节类型**：方法
- **核心主张**：3 张比例分配决定叙事权重，黑色间隔是剪辑呼吸
- **关键要点**：
  - **5 种标准比例分配**：
    - 经典均分：1:1:1
    - 强调首镜头：1.25:0.9:0.85
    - 强调中间：0.85:1.3:0.85
    - 强调余韵：0.85:0.9:1.25
    - 不均记忆条：0.7:1.2:0.75（6-16px 黑色呼吸间隔）
    - 残破监控条：均分 + 1 张更柔/低对比度
  - **黑色间隔**：作剪辑节奏，不是装饰
  - **禁止**：让 AI 模型自己拼 3 张图（拼接由 PIL/skills/scripts 外部做）
- **数据/数字**：5 比例分配 / 6-16px 间隔
- **金句**：3 张比例 = 叙事权重，黑色 = 剪辑呼吸。

## P6 · 导演风格转译

- **标题**：导演风格转译（Director DNA Translation）
- **副标**：不复制某导演的"滤镜"，提取视觉语法
- **章节类型**：方法
- **核心主张**：把"王家卫风格"转译成"具体视觉语言"（不是写"王家卫"）
- **关键要点**：
  - **禁止**：「王家卫风格」「维伦纽瓦配色」等命名导演
  - **转译方法**：把抽象风格 → 具体摄影/光线/构图/叙事
    - 例：低饱和冷调 + 长焦压缩 + 强 Order Composition + 余韵背影
  - **强度控制**：DIALOGUE_VERBOSITY + INFERENCE + DECISION 三维调节
- **数据/数字**：3 维强度调节
- **金句**：学导演的"为什么"，不学导演的"滤镜"。

## P7 · Mavis 工具栈适配（matrix MCP）

- **标题**：Mavis 工具栈适配
- **副标**：用 matrix_generate_image × 3 出 21:9 triptych
- **章节类型**：实战
- **核心主张**：cinema-dna 纯 prompt 设计，无外部 CLI 依赖，matrix MCP 直接用
- **关键要点**：
  - **不需要 ffmpeg**（纯图，无视频）
  - **不需要 scrub engine**（静态图）
  - **3 镜头出图**：matrix_generate_image × 3 并行，每张 21:9（aspect_ratio="21:9"）+ 2K
  - **拼接**：PIL 3 张按比例（1.25:0.9:0.85）拼接 + 8px 黑色间隔
  - **可后处理**（可选）：ffmpeg 加暗角 / film grain / color grading
  - **适用场景**：公众号配图 / 小红书封面 / 视频号封面 / 报告插图 / 公众号头图
- **数据/数字**：3 次 matrix 调用 + 1 次 PIL 拼接
- **金句**：cinema-dna = 纯 prompt，matrix MCP 天然适配。

## P8 · 工具对比与适用场景

- **标题**：工具对比（vs scroll-world / vs 普通 AI 配图）
- **副标**：3 种电影感生成的取舍
- **章节类型**：对比
- **核心主张**：cinema-dna 是"3 镜头叙事 + 21:9 横向"，不是"1 张精修大图"
- **关键要点**：
  - **vs 普通 AI 配图**：普通 = 1 张竖图 + AI 套词；cinema-dna = 3 张 21:9 + 摄影参数 + 叙事合同
  - **vs scroll-world**：scroll-world = 视频连续飞行；cinema-dna = 静态三联叙事。两者互补
  - **vs dashiai-ppt**：dashiai-ppt = 22 幕讲解演示；cinema-dna = 3 张电影感插图
  - **vs 公众号 7 段钩子链**：公众号 7 段是长文钩子链；cinema-dna 3 张是单主题叙事
  - **适用**：任何需要"高级感"的主题（产品发布 / 旅行记录 / 人物故事 / 空间转译 / 城市 / 季节）
  - **不适用**：纯科普 / 数据展示 / 长文（用其他方法）
- **数据/数字**：3 镜头 vs 22 幕 vs 7 段 vs 1 张
- **金句**：cinema-dna = 3 张 21:9 叙事；scroll-world = 视频连续；dashiai-ppt = 22 幕讲解。
