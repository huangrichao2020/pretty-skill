# P6 · 导演风格转译

## 5 字段

| 字段 | 内容 |
|---|---|
| **核心主张** | 学导演的"为什么"，不学导演的"滤镜" |
| **认知锚点** | 禁止命名导演（"王家卫风格" / "维伦纽瓦配色"）→ 转译为具体视觉语言 |
| **关键要点** | 抽象风格 → 具体摄影/光线/构图/叙事 4 维转译 + 3 维强度调节（DIALOGUE_VERBOSITY / INFERENCE / DECISION）|
| **数据** | 3 维强度调节 |
| **金句** | 学导演的"为什么"，不学导演的"滤镜" |

## 配套 example

- `eastern-palace-triptych.png` · 东方宫殿 · Order Composition 秩序构图 · 强 Order + 1 处打破

## Prompt（导演风格转译）

```text
# 反例：直接命名导演
"Wong Kar-wai style, 2046 era"  # ❌ AI 套词

# 正例：转译为视觉语言
# 假设要"王家卫风"，转译为：
- Low saturation, cool color body (cyan + amber accents)
- Long lens compression (85mm equivalent)
- Strong Order Composition with one meaningful break
- 4-decade aftertaste framing (back view, empty room, distant figure)
- 35mm film still texture
- 21:9 aspect ratio
```

## 3 维强度调节

| 维度 | 含义 | 调节 |
|---|---|---|
| `DIALOGUE_VERBOSITY` | 提示词对话/字句量 | 高 = 详细描述；低 = 留白 |
| `INFERENCE` | 推断空间 | 高 = 少给具体描述让模型推断；低 = 给全所有参数 |
| `DECISION` | 决策自主 | 高 = 模型自主；低 = 严格按预设 |

## 反模式

- ❌ "王家卫风格" / "是枝裕和色调" / "诺兰叙事"
- ❌ 1 个导演占 1 张图
- ❌ 风格用 1 个形容词（"冷""暖"）
