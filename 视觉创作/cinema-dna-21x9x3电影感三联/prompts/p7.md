# P7 · Mavis 工具栈适配

## 5 字段

| 字段 | 内容 |
|---|---|
| **核心主张** | cinema-dna = 纯 prompt，matrix MCP 天然适配 |
| **认知锚点** | matrix_generate_image × 3 并行 + PIL 拼接 1 张 triptych = 落地全部 |
| **关键要点** | 21:9 aspect_ratio + 2K + 3 张独立 prompt + PIL 3 段拼接 + 8px 黑色间隔 + 可选 ffmpeg 暗角/film grain |
| **数据** | 3 次 matrix 调用 + 1 次 PIL 拼接 + 0 ffmpeg 视频 |
| **金句** | cinema-dna = 纯 prompt · matrix MCP 天然适配 · 不需要 ffmpeg 视频 |

## 配套 example

- `dumpling-shop-triptych.png` · 饺子馆 · 烟火气 + 人物 30% · 实战题材

## Mavis 工具栈调用 sequence

```bash
# Step 1: 出 3 张独立 21:9 图（并行）
mavis mcp call matrix matrix_generate_image '{
  "requests": [
    {"prompt": "[Shot 1 prompt with 5+ photography params]", "aspect_ratio": "21:9", "resolution": "2K"},
    {"prompt": "[Shot 2 prompt]", "aspect_ratio": "21:9", "resolution": "2K"},
    {"prompt": "[Shot 3 prompt]", "aspect_ratio": "21:9", "resolution": "2K"}
  ]
}'

# Step 2: PIL 拼接 3 张为 triptych
python3 -c "
from PIL import Image
img1 = Image.open('shot1.png').convert('RGB').resize((426, 432))
img2 = Image.open('shot2.png').convert('RGB').resize((307, 432))
img3 = Image.open('shot3.png').convert('RGB').resize((290, 432))
gap = 8
canvas = Image.new('RGB', (1039, 432), (0, 0, 0))
canvas.paste(img1, (0, 0))
canvas.paste(img2, (434, 0))
canvas.paste(img3, (749, 0))
canvas.save('triptych.jpg', 'JPEG', quality=85)
"

# Step 3 (可选): ffmpeg 加暗角 / film grain
ffmpeg -i triptych.jpg -vf "vignette=PI/4,noise=alls=20:allf=t" triptych-final.jpg
```

## Mavis 适配性

| 优势 | 说明 |
|---|---|
| 0 外部 CLI 依赖 | 不需要 higgsfield / ffmpeg（除非做暗角） |
| 3 张出图 < 1 min | matrix 并行 |
| 拼接 < 1 sec | PIL 一行 |
| 总耗时 | **5-10 min / triptych** |
