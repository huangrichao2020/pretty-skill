# P5 · Triptych 节奏

## 5 字段

| 字段 | 内容 |
|---|---|
| **核心主张** | 3 张比例 = 叙事权重，黑色 = 剪辑呼吸 |
| **认知锚点** | 5 比例分配：经典均分 1:1:1 / 强调首 1.25:0.9:0.85 / 强调中间 0.85:1.3:0.85 / 强调余韵 0.85:0.9:1.25 / 记忆条 0.7:1.2:0.75 |
| **关键要点** | 黑色 6-16px 间隔作剪辑节奏 + 禁止让 AI 模型自己拼 3 张图 |
| **数据** | 5 比例分配 / 6-16px 间隔 |
| **金句** | 比例 = 叙事权重，黑色 = 剪辑呼吸 |

## 配套 example

- `journey-west-original-epic-triptych.png` · 西游主题 · 史诗开篇 · 可作为"强调首"1.25:0.9:0.85 范式

## Prompt（5 种 Triptych 节奏示例）

```text
# 强调首镜头（最常用）
Triptych rhythm: 1.25:0.9:0.85, Shot 1 占 1.25x（首镜最重，开场感强）

# 强调余韵
Triptych rhythm: 0.85:0.9:1.25, Shot 3 占 1.25x（结尾留白，余韵最强）

# 强调中间
Triptych rhythm: 0.85:1.3:0.85, Shot 2 占 1.3x（关系建立是核心）

# 经典均分
Triptych rhythm: 1:1:1, 3 张等权（最稳）

# 记忆条
Triptych rhythm: 0.7:1.2:0.75, 6-16px 黑色呼吸间隔（不均分，更像真实剪辑）
```

## PIL 拼接代码（p8 完整版）

```python
ratio1, ratio2, ratio3 = 1.25, 0.9, 0.85  # 强调首
total = ratio1 + ratio2 + ratio3
w1 = int(W * ratio1 / total)
w2 = int(W * ratio2 / total)
w3 = int(W * ratio3 / total)
gap = 8
canvas = Image.new("RGB", (w1+w2+w3+gap*2, H), (0,0,0))
# paste 3 images with gap
```
