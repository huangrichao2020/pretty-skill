## 核心论点

全栈应用不该从 0 写 · meoo-cli = 秒悟（Meoo）平台完整生命周期 · 项目初始化 + 本地开发 + 云服务开通 + 数据库管理 + 边缘函数部署 + CDN 发布。

## 核心方法论

### 1 · 触发场景
- 用户提到"秒悟"或"Meoo"
- 从零构建应用 · 需求可被以下架构覆盖：
  - 前端 SPA（React/Vue）
  - Supabase（数据库/Auth/Storage）
  - Deno 边缘函数
  - AI 大模型服务

### 2 · 完整生命周期
- 项目初始化（meoo init）
- 本地开发（meoo dev）
- 云服务开通（Supabase 集成）
- 数据库管理（迁移 / 表结构）
- 边缘函数部署（Deno）
- CDN 发布（一键）
- 沙箱代码同步
- 账户与权益管理

### 3 · 4 大技术组件
- 前端 SPA（React / Vue）
- Supabase（BaaS）
- Deno 边缘函数
- AI 大模型服务

### 4 · 与传统全栈开发差异
- meoo-cli：一键全栈 + AI 集成
- 传统：从 0 写后端 + 配数据库 + 部署
