## P2 · 失败模式与兜底树（新增 · 维度 1 优化）

> **核心主张**：进化要先知道"哪里会失败"，不是"哪里会成功"

### 2.1 · 4 类失败模式

| 失败模式 | 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|---|
| **命令执行失败** | 工具调用错 / API 超时 / 权限拒绝 | 重试 1 次（间隔 2s） | 切换备用工具 / 改写命令 |
| **输出质量低** | 用户纠正 / 内容跑偏 / 套话痕迹 | 识别 + 记录到 memory | 重写 + 反例黑名单更新 |
| **理解偏差** | 用户反馈"不是这个意思" | 反问 1 个澄清问题 | 引用历史 case 找共同模式 |
| **系统故障** | mavis daemon 崩 / 网络断 / token 用完 | 等待 + 状态检查 | 转 fallback 模式（人工介入）|

### 2.2 · 根因分析 SOP（5 Why）

```
错误发生
  ↓
Why 1: 为什么这个命令失败？
  ↓
Why 2: 为什么不重试就放弃？
  ↓
Why 3: 为什么不先检查工具状态？
  ↓
Why 4: 为什么没在 SKILL.md 写明失败处理？
  ↓
Why 5: 为什么之前犯过同样错误没记录？
  ↓
根因：缺少"失败模式编码"  →  写入 memory + 更新 skill
```

> **金句**：5 Why 不是仪式，是挖到根因的工具
- **认知锚点**：「失败模式倒立树」—— 根因分析 + 兜底分支

## P4 · 5 步工作流（深化）

```
错误发生
  ↓
Step 1 · 根因分析（5 Why · 不停在表面）
  ↓
Step 2 · 分类（命令失败 / 输出质量 / 理解偏差 / 系统故障）
  ↓
Step 3 · 记录（mavis memory agent/project/user 三层）
  ↓
Step 4 · 更新 skill（修 SKILL.md / 加反例黑名单）
  ↓
Step 5 · 下次预防（共识检查 · 不再犯）
```

- **关键要点**：
  - 每步必须输出（不能跳）
  - Step 3 写 memory 必须含 trigger + fix
  - Step 4 改 SKILL.md 必须用 Edit tool 不重写
- **数据 / 数字**：5 步 / 必填件 ≥ 3 项
- **金句**：5 步工作流 = 进化 pipeline
- **认知锚点**：「5 步工作流流水线」—— 收集-评估-提炼-调整-沉淀

## P5 · 反例黑名单 8 条（新增 · 维度 3 优化）

> **核心主张**：这 8 条 = AI 代理进化的最大障碍 · 必须显性知道 + 主动避开

### 5.1 · 反例黑名单

1. ❌ **重复犯同样错误**（不记 memory）
   - 反例：用户每次都说"不要用删 ①" → AI 仍然用
   - 修复：每次纠正 → `mavis memory append` → 下次自动避开

2. ❌ **不记录失败原因**（只记"失败了"）
   - 反例：日志写"工具调用失败" → 没记录为什么失败
   - 修复：必须含 trigger + reason + fix

3. ❌ **不更新 skill**（memory 有了但 SKILL.md 没改）
   - 反例：知道某条规则要改，但 SKILL.md 一直旧版
   - 修复：每月 review 一次 · 用 Edit tool 不重写

4. ❌ **不主动学习**（等用户纠正才动）
   - 反例：用户没纠正就不学
   - 修复：每日 dream 修炼（v0 已存在）+ 达尔文 2.0 评分（v1 新增）

5. ❌ **静默跳过异常**（catch 错误但啥都不做）
   - 反例：try/except 把错误吞了，用户看不到
   - 修复：错误必须显性记录 + 通知用户

6. ❌ **用 `git reset --hard` 当回滚**（达尔文 2.0 反例）
   - 反例：改错想回滚就 `git reset --hard HEAD~1` → 丢失中间 commit
   - 修复：用 `git revert <commit>` · 保留历史

7. ❌ **同一个 AI 又改又评**（达尔文 2.0 印证 · 单评委 46.4%）
   - 反例：让 AI 改完 SKILL.md 再让同一 AI 评分 → 评分作弊
   - 修复：多评委独立审查（每轮新评委）

8. ❌ **一轮内改多个维度**（达尔文 2.0 早停机制）
   - 反例：同时改 9 维评分 3 个维度 → 不知道哪个有效
   - 修复：每轮只改最低维度

> **金句**：8 条反例 = AI 代理的"禁止事项"
- **认知锚点**：「8 条反例黑名单」—— 8 种常见自我进化错误
