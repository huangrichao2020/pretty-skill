## 核心论点

AI 代理最大的浪费 = 同样错误犯 N 次 · self-improving-agent = 持续学习 + 错误纠正 + 性能优化 + 知识积累 + 自主成长 · 每次失败都变成下次更好。

## 核心方法论

### 1 · 触发场景
- 命令或操作意外失败
- 用户纠正 AI 错误
- 需要记录学习经验
- 提升代理性能
- 持续优化工作流程

### 2 · 5 项核心能力
- 捕获学习内容（错误 / 纠正 / 心得）
- 错误纠正（下次避免）
- 性能优化（识别低效）
- 知识积累（沉淀到知识库）
- 自主成长（自动应用）

### 3 · 5 步工作流
错误发生 → 根因分析 → 记录（mavis memory）→ 更新 skill / knowledge → 下次预防

### 4 · 4 大反模式
- ❌ 重复犯同样错误
- ❌ 不记录失败原因
- ❌ 不更新 skill
- ❌ 不主动学习
