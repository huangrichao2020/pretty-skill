## P3 · Part 1 — 第一层 · 四象限评估

- **章节类型**：核心解法（STAR-C 案例 + 第一层方法论）
- **核心主张**：人效痛点四象限评估 = 黄金场景长这样
- **认知锚点**：「四象限评估盘」—— 流量/转化/复购/利润 4 维评估
- **4 象限**：
  - **左上「高重复 + 高耗时」** ⭐ 黄金场景：客服标准咨询每天 80 次、每次 5 分钟
  - **右上「低价值 + 强规则」** 次黄金：订单审核按 SKU 走规则
  - **左下「高重复 + 低价值」** 改造意义小：活动推送群发
  - **右下「低重复 + 高价值」** 暂缓：客诉升级情感沟通
- **评估规则**：
  - 四维度全高 = 黄金场景 → 优先改造
  - 三维度满足 = 可改造
  - 1-2 维度满足 → 先做 SOP 优化
- **数据 / 数字**：4 象限 / 4 维度（高重复 / 高耗时 / 低价值 / 强规则）
- **金句**：「高重复 × 高耗时 × 低价值 × 强规则 = AI 改造优先级最高」
- **童趣图标**：对话气泡 / 尺子 / 扩音器 / 手握手

## P4 · Part 2 — 第二层 · 原子级 + 六维

- **章节类型**：核心解法（STAR-C 案例 + 第二层方法论）
- **核心主张**：拆到原子 + 六维评估 = 每个动作都有 AI 替代答案
- **认知锚点**：「原子级 + 6 维矩阵」—— 拆到最小可执行单元
- **Step 4 原子级拆解**（浅蓝 #BDE0FE）：
  - 反例：「处理客户咨询」← 太粗
  - 正例：「打开对话 → 判断问题类型 → 查询订单状态 → 组织回复话术 → 发送回复」（5 步原子动作）
- **Step 5 六维评估**（薄荷绿 #C7F0BD）：
  - 6 维：规则明确性 / 执行重复性 / 数据结构化 / 情境可预测性 / 错误可承受性 / 人机协作必要性
  - 高 = 客服标准咨询 → 类型 A
  - 中 = 售后客诉 → 类型 B
  - 低 = 选品策略 → 类型 C
- **数据 / 数字**：6 维
- **金句**：「一个人在一个时间段内完成 + 有明确输入输出 = 原子级」
- **童趣图标**：5 个原子动作小图标 / 6 维表头格子 / 头脑涂鸦

## P5 · Step 6 — 3 种 Skill 类型归类

- **章节类型**：深化 / 双案例对照 + 金句嵌
- **核心主张**：不是所有场景都要 AI 全自动
- **认知锚点**：「3 种 Skill 类型抽屉」—— 内容/工具/决策 3 类
- **类型 A**（浅蓝 #BDE0FE）：基础 Skill · **全自动** / 六维全高 / 案例：数据报表每日自动生成、订单 SKU 自动审核 / 自动化 100% / 人工角色：零介入
- **类型 B**（薄荷绿 #C7F0BD）：业务场景 Skill · **AI 主导** / 六维中高 / 案例：商品文案 / 短视频脚本 / 客服回复 / 自动化 70% / 人工角色：关键节点确认
- **类型 C**（桃粉 #FFB5BA）：认知增强 Skill · **AI 辅助** / 六维中低 / 案例：选品决策 / 客诉升级 / 社群温度感 / 自动化 30% / 人工角色：人工决策执行
- **数据 / 数字**：A=32% / B=49% / C=19%（三种类型在 41 场景的占比）
- **金句**：「AI 替代率 89% 不是技术问题，是认知问题 —— 知道什么该全自动，什么必须人做」
- **童趣图标**：齿轮 + 闪电 + 文档 / AI 大脑 + 流程箭头 / 灯泡 + 数据 + 人

## P6 · Part 3 — 4 角色升级

- **章节类型**：角色升级（"X 不是 Y，是 Z" 句式）
- **核心主张**：4 个角色从执行者升级到治理者
- **认知锚点**：「4 角色升级魔方」—— 选品师/内容师/投手/复盘师
- **4 角色升级**：
  - **内容生产者 → 文案策略师**（浅蓝 #BDE0FE）：从「一天写 5 条文案」到「审 100 条 AI 文案 + 选 5 条最优」
  - **客服 → 客户成功**（薄荷绿 #C7F0BD）：从「回复 80 个标准咨询」到「处理 5 个 AI 转交的复杂客诉」
  - **选品经理 → 数据策略师**（桃粉 #FFB5BA）：从「盯数据看趋势」到「让 AI 给 10 个候选 + 你选 1 个」
  - **运营管理者 → AI 编排师**（奶黄 #FFE5A5）：从「管人派活」到「编排 Skill 流水线 + 设计反馈闭环」
- **数据 / 数字**：4 角色
- **金句**：「不是 AI 替代你，是会用 AI 的同行替代你。」
- **童趣图标**：钢笔 → AI 大脑 / 耳机 → 握手 / 货架 → 数据 / 齿轮 + 链条

## P7 · Takeaways — 3 件 90 天必做

- **章节类型**：收束 / 三层收尾 + 行动号召金句
- **核心主张**：3 件 90 天内必做
- **认知锚点**：「90 天 3 件必做清单」—— 立刻可执行起步
- **3 件事**：
  - **01 画四象限盘点自家 5 个子流程**（浅蓝 #BDE0FE）—— 找黄金场景：四维全高的子流程 = AI 改造优先级最高
  - **02 选 1 个场景拆到原子级 + 六维评估**（薄荷绿 #C7F0BD）—— 拆得够细，类型归类才精准 —— A/B/C 才有依据
  - **03 用第一期（0-30 天）跑通类型 A 场景**（桃粉 #FFB5BA）—— 数据报表、订单审核这种类型 A 场景，先释放 2-3 人力
- **数据 / 数字**：3 件事 / 90 天
- **金句 1**：「不是 AI 淘汰你，是用 AI 的同行淘汰你；不是技术问题，是认知问题」
- **金句 2**：「今天带走的表格，6 个月后贬值 50%。唯一不贬值的是 —— 持续拆解的能力」
- **童趣图标**：四象限 + 放大镜 / 拆解 + 6 维表 / 日历 + 火箭
