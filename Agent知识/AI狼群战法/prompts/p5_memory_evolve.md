【画面要点】
- 顶部小字：「OBSERVATION · MEMORY EVOLVE」
- 主标题：「从人类反馈中提炼规则，让 Agent 自主进化」
- 副小字：「团队成员的角色从『执行者』变成『监督者』和『反馈者』」（珊瑚粉 #FF6B9D 强调引号）

- 中央左右两个对照案例：
  - **左：正向反馈 Positive**（薄荷绿 #C7F0BD 卡片）：

    - → 团队标记「优秀案例」
    - → Memory Update：「这种语气和结构的邮件转化率高」
    - 配图标：信封 + 笑脸 + 星标

  - **右：负向反馈 Negative**（奶黄 #FFE5A5 卡片）：
    - 「研发发现 Agent 生成的代码有性能问题」
    - → 修改并提交
    - → Agent 捕获修改差异
    - → Memory Update：「处理大规模并发时，避免使用低效循环」
    - 配图标：齿轮 + 警告标 + 修复扳手

- 底部金句大字：「团队的共同目标是：养好这个 Agent。」手写感
