## 这个 case 是什么

**页数**：4 页 · **领域**：Agent知识

## 核心论点

反爬网页不该用 WebFetch · browser-act = 浏览器 Stealth mode + Cookie 持久化 + JS 渲染 + 反指纹 + 频率控制。

## 5 大场景

| 场景 | 难度 | 优势 |
|---|---|---|
| 公众号文章抓取 | 高 | 动态渲染 + 微信反爬 |
| 小红书笔记抓取 | 高 | 登录态 + 反爬指纹 |
| 知乎专栏/回答 | 中 | 长文 + 折叠内容 |

## 4 步工作流

1. 目标识别（网站 URL + 反爬强度）
2. 策略选择（stealth-extract / 浏览器自动化）
3. 执行（保持登录态 + 频率控制 + 反指纹）
4. 数据落地（结构化输出 + 去重）

## 与 WebFetch 差异

- **WebFetch**：公开静态页面 · 简单抓取 · 易被反爬拦截
- **browser-act**：动态渲染 + 登录态 + 反指纹 + JavaScript 执行

## 关键能力

- ✅ Stealth mode（隐藏自动化痕迹）
- ✅ Cookie 持久化（登录态保持）
- ✅ JavaScript 渲染（动态内容）
- ✅ 频率控制（避免触发限流）
- ✅ 反指纹（避免被识别为机器人）
