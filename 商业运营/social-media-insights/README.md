## 这个 case 是什么

**页数**：4 页 · **领域**：商业运营

## 核心论点

社媒内容不该凭感觉 · social-media-insights = 抓取公开内容 + 深度分析 + 竞品对比 + 行动建议 = 数据驱动内容运营。

## 5 大能力

- 自动抓取（公众号 + 小红书公开内容）
- 整理分类（按主题/时间/互动量）
- 深度分析（内容结构 + 标题 + 配图 + CTA）
- 竞品分析（多账号对比 + 差异化定位）
- 行动建议（选题 + 风格 + 发布时机）

## 4 步工作流

1. 账号选择（指定公众号 + 小红书账号）
2. 内容抓取（mavis browser 自动化 + 反爬）
3. 深度分析（标题公式 + 选题分布 + 互动数据 + 风格特征）
4. 输出报告（竞品对比 + 行动建议）

## 报告内容

- 选题分布图（哪些选题最火）
- 标题公式汇总（爆款标题模板）
- 发布时间分析（最佳发布时机）
- 内容风格特征（语言/排版/视觉）
- 互动数据（阅读/在看/评论/转发）
- 行动建议（自己账号的优化方向）
