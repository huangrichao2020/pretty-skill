# ImageGen Prompt 格式说明

每个 prompt 文件对应一页幻灯片。三段式结构：

## 模板

```text
手绘科教风 + 马卡龙经典配色 · 16:9 横幅，2K 高清。

【主题】{页面标题}
【副标】{副标题}
【副副标】{第三行，封面专用}
【作者小字】{封面专用}

【画面要点 - AI 自由发挥布局】
- {布局描述，含图标位置、数据卡片排列}
- {关键元素颜色强调}
- {不锁死布局，让 AI 自由发挥}

【风格锁】
- 底色：{hex}
- 主色：{2-5 个 hex}
- 强调色：{hex}
- {质感：手绘笔触 / 蜡笔 / 涂鸦线 或 直角纯色无阴影}
- {装饰：童趣图标类型 或 hairstyle 分隔线}
```

## 实际范例

见本目录下的 prompt 文件（如 p0_cover.md, p1_hook.md 等）。

## 约束

- ❌ 不要在 prompt 里写 "X 色 强调 Y"（AI 会当文案画进去）
- ❌ 不要锁死布局——让 AI 自由发挥
- ❌ 不要超过 100 行（堆字体铁律禁锢 AI）
- ✅ 每页 60 行内
- ✅ 中文用语
- ✅ 约束：16:9 / 2K / 无错字
