# sales-powermap · B2B 销售攻单 Power Map

---

## 这个 case 是什么

**页数**：4 页 · **领域**：社交主导

## 核心论点

B2B 销售不该只靠关系 · sales-powermap = 目标客户发现 + 组织架构挖掘 + Power Map 可视化 + 攻单方案 · 5 步闭环。

## 5 步工作流

1. 意图解析（销售目标 + 客户画像）
2. 目标客户发现（qcc-company 行业/规模/地域）
3. 组织架构挖掘（法人/股东/高管/决策链）
4. Power Map 构建（关系图 + 影响力 + 决策权重）
5. 攻单方案输出（触达路径 + 关键话术）

## Power Map 输出

```
├── 客户公司基本信息
├── 决策链（高层 / 中层 / 执行层）
├── 关键决策人（影响力 + 立场）
├── 利益相关方（支持者 / 中立 / 反对者）
└── 攻单建议（触达顺序 + 话术 + 时机）
```
