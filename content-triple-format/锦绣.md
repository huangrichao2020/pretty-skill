# 锦绣范式 · Jinxiu (v3 首次提出)

> **TL;DR**：**锦绣 = 把任何知识 / skill 在创建时就"绣"成易传播的视觉作品**。每个 case 提交时，**自动生成** 1 套多平台传播素材（朋友圈 1 张 + 小红书 9 张 + 公众号 12 页 + 视频脚本）。

---

## 🎯 为什么需要"锦绣"

### 3F Content 解决了什么 + 没解决什么

| 范式 | 服务对象 | 解决了什么 | 没解决什么 |
|---|---|---|---|
| **3F Content**（v1-v2）| **AI** | AI 能直接消化（.md 喂 LLM）| ❌ 给人看 = 文字 PPT（丑）|
| **锦绣**（v3 新增）| **人** | 一眼懂 + 视觉冲击 + 易传播 | ❌ 不能被 AI 消费（视觉是给人的）|

**3F Content + 锦绣 = AI 友好 + 人易传播 = 完整闭环**。

### 锦绣 vs 传统 PPT

| 维度 | 传统 PPT | 锦绣 |
|---|---|---|
| 创建时机 | 事后补救 | **创建时自动生成** |
| 平台适配 | 单一（PowerPoint） | **4 平台 1 套素材**（朋友圈 + 小红书 + 公众号 + 视频）|
| 传播性 | 强（演示场景）| **更强**（社交媒体 + 短视频）|
| 视觉冲击 | 中（看设计）| **高**（专为传播设计）|

## 📐 锦绣 4 种形态

### 形态 1 · 锦绣封面（1 张 16:9 大图）

**用途**：朋友圈 / 推特 / 微博分享  
**规格**：1920×1080（2K / 16:9）  
**元素**：
- 大标题（30% 画面）
- 视觉冲击元素（图标 / 抽象图形）
- 1 句话总结（20% 画面）
- 作者 / 来源水印（5% 画面）
- 大量留白（呼吸感）

**示例**：

```
┌─────────────────────────────────┐
│                                 │
│   4 重防御 · 让文字 PPT 无处逃    │
│                                 │
│      [盾牌 + 锁链 视觉]          │
│                                 │
│   pretty-skill 3F Content        │
│   范式硬约束 · 30 分钟跑通 PR     │
│                                 │
│                        @huangrichao2020 │
└─────────────────────────────────┘
```

### 形态 2 · 锦绣 PPT（8-12 页完整讲解）

**用途**：小红书 9 图 / 公众号 / 知乎 / 演讲  
**结构**：

| 页 | 类型 | 内容 |
|---|---|---|
| 1 | 封面 | 大标题 + 视觉 + 副标 |
| 2 | 钩子 | 1 个痛点 / 反常识 / 钩子问题 |
| 3 | 总纲 | N 个要点预告（视觉化）|
| 4-9 | 核心解法 | 每页 1 个核心观点 + 视觉 + 案例 |
| 10 | 反面 | 反例 / 易踩坑 |
| 11 | 行动 | 5 步可操作建议 |
| 12 | 收束 | 金句 + 关注 / 收藏 / 转发 |

**与 3F Content PPT 的区别**：
- 3F Content PPT = 演示场景（深色 / 复杂 / 信息密）
- 锦绣 PPT = 传播场景（浅色 / 简洁 / 1 屏 1 观点）

### 形态 3 · 锦绣网页版（移动友好）

**用途**：微信群 / 推友 / 链接分享  
**结构**：
- 顶部 1 张大图（移动端首屏震撼）
- 9 个独立小节（适合手机竖屏滑动）
- 底部 1 个二维码（关注 / 加群）

### 形态 4 · 锦绣视频脚本（30-60 秒讲解）

**用途**：抖音 / 视频号 / B 站 / 短视频平台  
**结构**：
- 0-3 秒：钩子（痛点 / 反常识）
- 3-10 秒：核心观点（1 句话）
- 10-50 秒：3-5 个要点（快节奏）
- 50-60 秒：行动号召（关注 / 收藏 / 评论）

## 🤖 锦绣自动生成（skill-creator）

> **任何知识 → 1 键生成完整锦绣素材**

```bash
# 未来
pip install pretty-skill
pretty-skill create \
  --input my-knowledge.md \
  --domain "金融投资" \
  --style "深色科技风"

# 输出：
# 锦绣/cover-朋友圈.png         (1 张大图)
# 锦绣/xiaohongshu-9图/         (9 张图)
# 锦绣/public-account-ppt/     (12 页 PPT)
# 锦绣/video-script.md         (30-60 秒脚本)
```

## 📊 锦绣 vs 3F Content 对比

| 维度 | 3F Content | 锦绣 |
|---|---|---|
| **服务对象** | AI | 人 |
| **输出形式** | .md / .pptx / .html | 1 大图 + 9 图 + 12 页 PPT + 视频脚本 |
| **平台** | 通用 | 朋友圈 / 小红书 / 公众号 / 视频 |
| **创建时机** | 必须（提交前）| **必须（提交前自动生成）** |
| **可被 AI 消费** | ✅ | ❌（视觉是给人的） |
| **可被人消费** | ⚠️（可读但不传播）| ✅（专门为传播设计） |

**3F Content + 锦绣 = 完整闭环**：
- 3F Content = 数据层（AI 消费）
- 锦绣 = 传播层（人消费）
- 两个一起 = 知识既被 AI 消化又被人传播

## 🛠️ 实际工作流（v3 推荐）

```
1. 用户写 content.md（4-7 字段每页）          ← 数据
   ↓
2. skill-creator 跑                          ← 自动化
   ├─ 出 9 张 AI 图（images/）
   ├─ 生成 PPTX（presentation.pptx）
   ├─ 生成 HTML（web.html）
   └─ 生成锦绣 4 形态（锦绣/）
   ↓
3. 人类编辑锦绣（30 分钟调优视觉）            ← 人机协作
   ↓
4. 跑 check-3f.py + 锦绣校验                  ← 自动化校验
   ↓
5. 提 PR → GitHub Actions 自动跑 → merge    ← 全球共建
```

**关键**：
- 步骤 1-2 是机器做的（80% 自动化）
- 步骤 3 是人做的（20% 调优视觉）
- 步骤 4-5 是工具做的（100% 自动化）

---

## 💯 设计原则

> **知识的价值 = 创作质量 × 传播质量**。
> 创作质量 = 3F Content（数据 + AI 友好）。
> 传播质量 = 锦绣（视觉 + 多平台）。
> 两者都要 = 才能让知识"既被 AI 学，又被人传"。
