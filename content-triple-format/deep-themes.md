# 视觉风格预设（Deep Themes）

> 补充 pretty-skills 默认的马卡龙手绘风，增加金融/研报向的深色科技风，以及它们各自适用的场景和严格约束。

## 预设 1：🎨 手绘叙事 + 马卡龙（pretty-skills 默认）

| 属性 | 值 |
|---|---|
| 底色 | 奶油粉 `#FFF5F5` |
| 主色 | 浅蓝 `#BDE0FE` · 薄荷绿 `#C7F0BD` · 奶黄 `#FFE5A5` · 桃粉 `#FFB5BA` · 淡紫 `#D8BFD8` |
| 强调 | 珊瑚粉 `#FF6B9D` |
| 质感 | 手绘涂鸦线 · 蜡笔/马克笔 · wobbly outlines · 童趣图标 |
| 适用 | 培训课件 / 知识沉淀 / 人文分享 / 内部培训 |

## 预设 2：🖥 深色科技风（Kun 贡献 · 2026-07-08）

| 属性 | 值 |
|---|---|
| 底色 | 深黑 `#0D1117` |
| 卡片底 | 深灰 `#161B22` · 边框 `#21262d` · 细分 `#30363d` |
| 强调 | 青绿色 `#00D4AA`（cyan accent） |
| 涨 | 红 `#FF5E5B`（A 股惯例） |
| 跌 | 绿 `#1AA260` |
| 次文字 | `#8B949E` / `#484F58` |
| 标题 | `#F0F6FC`（近乎白） |
| 质感 | 无阴影 · 无圆角 · 无渐变 · hairline 分隔线 · 行悬停微亮 |
| 适用 | 研报 / 交易复盘 / 金融数据 / 技术深度分析 |

### 深色风 ImageGen prompt 模板

```text
【风格锁】
- 底色：深黑 #0D1117
- 卡片/面板：深灰 #161B22
- 强调色：青绿 #00D4AA
- 无渐变、无阴影、无圆角
- 极简线框分隔，hairline 1px 灰色
- 数据大字报式排布，留白充分
- 正文浅灰 #8B949E，标题近乎白 #F0F6FC
```

## 风格锁规则（仓库级硬约束）

1. **一份 deck 只用一套预设**，中途不换色。
2. **不与默认马卡龙混搭**——选深色就深到底。
3. ImageGen prompt 的「【风格锁】」段必须逐字写清以上 hex 值。
4. 深色风额外要求：直角纯色、无 border-radius、无 box-shadow、无 gradient。
