## 视觉风格（6 套预设）

- **马卡龙** —— 浅蓝 + 薄荷绿 + 奶黄 + 桃粉
- **古铜金** —— 深红 + 金 + 棕
- **蓝白灰** —— 蓝 + 白 + 灰
- **深色科技风** —— 深黑 + 青绿 + 红涨绿跌 A 股
- **城市插画** —— 多色 + 线条
- **真实生活感** —— 暖色 + 真人
