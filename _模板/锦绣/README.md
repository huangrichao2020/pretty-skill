# 锦绣 PPT 模板 · v3.1 简化版

> 这是 skill-creator 工具自动生成锦绣素材时的内部模板。
> 贡献者通常**不需要手动编辑**——`skill-creator create` 会自动填入。

## v3.1 简化结构（按形式切 · 不锁死平台）

```
锦绣/
├── cover-横屏.png       # 1 张横屏封面（16:9 · 1920×1080）
├── cover-竖屏.png       # 1 张竖屏封面（3:4 · 1080×1440 或 9:16 · 1080×1920）
├── slides/              # 8-12 张讲解图（16:9 · creator 自行决定数量）
│   ├── slide-1.png
│   ├── slide-2.png
│   └── ...
└── readme.md            # 1 份融合 md（公众号 + 自媒体稿 + AI 阅读 三用）
```

## 平台映射（creator 自决定发哪）

| 形式 | 推荐平台 |
|---|---|
| cover-横屏.png | 朋友圈 / 推特 / 微博 / 视频封面 / 公众号题图 |
| cover-竖屏.png | 小红书 / Instagram / 抖音 / 视频号 |
| slides/ | PPT / 公众号文章图 / 知乎 / 视频 / 海报 / ... |
| readme.md | 直接发公众号 + 当自媒体讲解稿 + AI 阅读使用 |

## readme.md 模板

```markdown
# {案例标题}

> **作者**：@xxx
> **领域**：xxx
> **风格**：xxx
> **页数**：8-12 张讲解图 + 2 封面

---

## 导语（公众号开头 · 自媒体稿开头）

{1-2 段导语，口语化}

> **核心要点**（AI 友好 · 1 屏可读）：
> - 要点 1
> - 要点 2
> - 要点 3

---

## 第 1 章 · {章节名}

> **公众号正文 / 自媒体稿**：{口语化讲解段落 · 200-400 字}
>
> **核心要点**：
> - 要点 1
> - 要点 2
>
> **配图**：[slides/slide-1.png](slides/slide-1.png)
```
