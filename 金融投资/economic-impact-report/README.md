---

## 这个 case 是什么

**页数**：4 页 · **领域**：金融投资

## 核心论点

经济事件不该只看单一市场 · economic-impact-report = 政策动向 / 宏观冲击 / 产业演变 / 重大事件 → 跨市场传导链分析 · 重点覆盖中国因素扩散。

## 4 类事件覆盖

| 事件类型 | 跨市场影响 |
|---|---|
| 政策动向 | A 股板块 → 港股 → 美股中概 |
| 宏观冲击 | 利率/汇率/通胀/财政 → 跨市场 |
| 产业演变 | 上下游传导链 |
| 重大事件 | 标的筛选 + 估值影响 |

## 4 步工作流

1. 事件识别（政策/宏观/产业/重大事件）
2. 传导分析（5 步法：源事件 → 行业 → 个股 → 估值）
3. 数据支撑（MiniMax Finance MCP + web_search）
4. 输出（visual-page skill → GUI/HTML 报告）

## 不适用

- ❌ 独立的跨资产交易策略
- ❌ 泛新闻摘要
- ❌ 单一市场分析
