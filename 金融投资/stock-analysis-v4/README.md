## 核心论点

股票分析不该只靠单一数据源 · stock-analysis-v4 = 4 层架构（腾讯 API 优先 + 网页搜索 + MCP 工具 + 本地缓存）+ 强制触发 + 股票代码识别转换系统。

## 核心方法论

### 1 · 强制触发
输入含"股票代码/名称/分析/行情"等词时必须调用本 skill

### 2 · 4 层架构
- L1 腾讯 API（实时行情 / K 线 / 资金流）
- L2 网页搜索（新闻 / 公告 / 研报）
- L3 MCP 工具（qcc-company / qcc-operation / qcc-risk）
- L4 本地缓存（沪深 / 港股 / 美股历史数据）

### 3 · 6 大功能
- 实时行情 · K 线分析
- 资金流向 · 主力动向
- 公告 / 研报 / 新闻
- 财务 / 风险扫描
- 股票代码识别（支持 A 股 / 港股 / 美股）
- 缓存加速（二次查询 < 1s）

### 4 · 与 v2/v3 差异
- v4.0.5：4 层架构 · 强制触发 · 跨市场
- stock-analysis-llm（v2+v3）：4 大分析师 + LLM 辩论 · 已合并入 v4
