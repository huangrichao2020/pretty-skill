# event-driven-analyzer · 多市场事件驱动分析器

> **一句话定位**：有确定日期事件 → 路径 + 概率 + 回报 + 期望收益分析

---

## 这个 case 是什么

**页数**：4 页 · **领域**：金融投资

## 核心论点

事件驱动交易不该拍脑袋 · event-driven-analyzer = 并购重组/要约收购/再融资/回购/解禁/监管诉讼/指数事件 → 5 步法路径分析 + 概率评估 + 期望收益。

## 5 类事件

| 事件 | 关键日期 | 关键条款 |
|---|---|---|
| 并购重组 | 公告日/股东大会日 | 对价/换股比例 |
| 要约收购 | 收购期/要约价 | 溢价率/触发条件 |
| 再融资 | 预案日/批文日 | 募资额/发行价 |
| 回购 | 预案日/实施期 | 金额/价格区间 |
| 解禁 | 解禁日 | 数量/占比/性质 |
| 监管诉讼 | 立案日/判决日 | 涉案金额/影响 |
| 指数事件 | 调样日 | 调入/调出 |

## 5 步工作流

1. 事件识别（类型 + 日期 + 关键条款）
2. 历史数据（同类事件历史回报分布）
3. 路径推演（3-5 条主路径 + 概率）
4. 期望收益（加权回报 + 置信区间）
5. 输出（visual-page skill → GUI 报告）

## 关键约束

- ✅ 套用各市场交易日历与执行约束
- ✅ 期望收益 + 概率 + 路径 = 完整框架
- ✅ T+1 / 涨跌停 / 停牌 执行约束

## 不适用

- ❌ 一般催化剂清单
- ❌ 个人交易指令
- ❌ 模糊事件（无确定日期）
