# event-driven-analyzer

> [3F Content 范式](../../content-triple-format/) · F1 源文字版

## P0 · 封面
- 有确定日期事件 → 路径 + 概率 + 期望收益

## P1 · 5 类事件
并购重组 / 要约收购 / 再融资 / 回购 / 解禁 / 监管诉讼 / 指数事件

## P2 · 5 步工作流
事件识别 → 历史数据 → 路径推演 → 期望收益 → visual-page GUI 输出

## P3 · 关键约束
套用交易日历 / T+1 / 涨跌停 / 停牌

## P4 · 不适用
一般催化剂清单 / 个人交易指令 / 模糊事件
