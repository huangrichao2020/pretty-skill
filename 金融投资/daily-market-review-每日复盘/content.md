- **标题**：每日复盘

## P1 · 痛点切入

- **标题**：为什么"每日复盘"90% 翻车
- **副标**：罗列数据 vs 四层诊断
- **章节类型**：核心解法
- **核心主张**：90% 复盘翻车是因为只罗列数据（指数涨/跌、涨停家数）——没有"诊断"层；四层融合把数据翻译成"该不该做、做什么"
- **认知锚点**：「4 大复盘翻车坑」

```text
翻车坑 1：数据罗列
  表现：指数 + 涨停家数 + 成交额，没解读
  解决：四层融合（数据 → 诊断 → 行动）

翻车坑 2：单一层
  表现：只看情绪（涨停家数）或只看产业（政策）
  解决：四层并行 + L0 否决

翻车坑 3：错层判断
  表现：L2 产业好就买（但 L0 人性崩了）
  解决：L0 > L1 > L3 > L2 否决权层级

翻车坑 4：无下周指引
  表现：复盘完没下周/下月机会方向
  解决：住相 + 执念阶段 + STW 周期 三维度推演
```

- **数据 / 数字**：4 大坑 / 90% 翻车率
- **金句**：数据是原料，诊断是菜，行动是上桌

## P2 · 四层融合框架

- **标题**：L0 人性 / L1 情绪 / L2 产业 / L3 证据 · 否决权 L0 > L1 > L3 > L2
- **副标**：四层并行，逐层判断
- **章节类型**：核心解法
- **核心主张**：四层融合 = 4 个层级的独立判断 + 否决权规则（L0 一票否决）
- **认知锚点**：「四层融合矩阵」

```text
L0 人性层（最高否决权）
  核心：住相信号链 + 执念阶段
  5 维信号：龙头乏力 / 跟风先跑 / 扩散停止 / 情绪背离 / 资金转向
  判定：≥3 灯亮 = 减仓信号生效
  执念：确认 → 发酵 → 分歧 → 高潮 → 衰退 → 退潮

L1 情绪层
  核心：STW 情绪周期
  阶段：冰点 / 复苏 / 高潮 / 退潮
  指标：涨停家数 + 炸板率 + 封板率

L2 产业层
  核心：今天热点有真实因果逻辑吗？
  检查：政策催化 / 业绩兑现 / 供需拐点 / 还是题材轮动？

L3 证据层
  核心：支撑方向的证据等级
  等级：Tier A（趋势确认）/ B（有逻辑待验证）/ C（情绪修复）/ D（高风险）
```

- **关键要点**：
  - L0 必查（最高否决）→ L1 必查（情绪温度）→ L2 检查（产业逻辑）→ L3 评级（证据）
  - L0 崩了 = 任何 L1/L2/L3 都不算数
  - **L0 不是"看多空"** — 是"看群体信念在形成还是崩塌"
- **数据 / 数字**：4 层 / 5 维 / 6 阶段 / 4 等级
- **金句**：L0 否决权 = 群体信念 = 恐惧的边界

## P3 · L0 住相信号链（核心深挖）

- **标题**：L0 5 维住相信号 · 执念 6 阶段
- **副标**：最高否决权 = 群体信念在崩塌吗？
- **章节类型**：核心解法
- **核心主张**：L0 = 5 维住相信号 + 6 执念阶段，逐条判断"群体信念是在形成还是崩塌"
- **认知锚点**：「5 维信号 + 6 阶段」

```text
5 维住相信号（≥3 亮灯 = 减仓）
  1 龙头乏力：连板高度下降 / 龙头切换频繁
  2 跟风先跑：板块涨跌比 < 0.5 / 后排股先跌
  3 扩散停止：热点集中 1-2 个 / 新方向不再出现
  4 情绪背离：指数涨但涨停少 / 或指数跌但涨停多
  5 资金转向：主力净流出 > 100 亿 / 午后集中抛售

6 执念阶段
  确认 → 发酵 → 分歧 → 高潮 → 衰退 → 退潮
  每阶段对应的市场行为特征
  实战：阶段判断 → 调整仓位 + 选股风格
```

- **关键要点**：
  - 5 维信号灯是"自检清单"，逐条对照当日盘面
  - 执念阶段判断要**结合多日数据**，不是单日判断
  - L0 崩了，最快反应 = 减仓 + 防御
  - L0 强（0-1 灯亮）= 进攻/持有
- **数据 / 数字**：5 维 / 6 阶段 / 3 灯阈值
- **金句**：5 维亮 3 灯 = 减仓信号

## P4 · L1 STW 情绪周期

- **标题**：L1 情绪层 · 冰点 / 复苏 / 高潮 / 退潮
- **副标**：涨停家数 + 炸板率 = 情绪温度计
- **章节类型**：核心解法
- **核心主张**：L1 情绪周期 = STW 四阶段，**涨停家数 + 炸板率** 是核心温度计
- **认知锚点**：「STW 4 阶段温度表」

```text
冰点（不宜割肉）
  涨停：< 20 只
  炸板率：高
  策略：等修复，不追不割

复苏（可观察参与）
  涨停：30-60 只
  封板率：回升
  策略：选强势龙头试错

高潮（谨慎追高）
  涨停：> 80 只
  炸板率：低
  策略：龙头已涨多，警惕分歧

退潮（防守为主）
  涨停：< 30 只
  炸板率：升
  策略：减仓 + 等待新一轮冰点
```

- **关键要点**：
  - STW = 冰点 / 复苏 / 高潮 / 退潮（4 阶段循环）
  - 涨停家数是滞后指标，要结合炸板率一起看
  - 退潮期不要抄底，等冰点确认
  - 高潮期不要追涨，等分歧确认
- **数据 / 数字**：4 阶段 / 4 阈值
- **金句**：冰点割肉 = 双杀；高潮追涨 = 接力最后一棒

## P5 · 默认设置 + 路由 + 怎么用

- **标题**：默认 4 层并行 · 5 步诊断 SOP
- **副标**：开盘前 / 盘中 / 收盘后怎么用
- **章节类型**：收束
- **核心主张**：本 skill 默认走 4 层并行 + 5 步诊断 SOP，**每日复盘不是负担，是习惯**
- **认知锚点**：「5 步诊断 + 3 时段使用」

```text
5 步诊断 SOP
  Step 1 拿数据：5 大指数 + 8 指标（curl 腾讯 API + WebSearch）
  Step 2 L0 5 维信号：逐条对照（≥3 灯 = 减仓）
  Step 3 L1 STW 周期：判断冰点/复苏/高潮/退潮
  Step 4 L2 产业逻辑：板块催化是政策/业绩/题材？
  Step 5 L3 证据评级：Tier A/B/C/D

3 时段使用
  开盘前：看 L0 昨日信号 + 今日开盘预期
  盘中：监控 L0 新信号 + L1 STW 切换
  收盘后：5 步 SOP 完整走一遍 + 写 daily 日志

输出
  可视化复盘卡片（widget 渲染）
  daily 日志（追加到 .md 文件）
  下周/下月机会方向
```

- **关键要点**：
  - 与 `portfolio-diagnosis-持仓诊断` 互补：每日复盘是"市场体检"，持仓诊断是"组合体检"
  - 同样 4 层融合，但 L2/L3 颗粒度不同（市场 vs 持仓）
  - 同理用 `serenity-stock-choke` 做产业链卡脖子分析 + `technical-signal` 做个股技术面
  - 数据源：腾讯行情 API 实时 + WebSearch 板块资金流 + 复盘日志历史
- **数据 / 数字**：4 层 / 5 步 SOP / 8 指标 / 3 时段
- **金句**：复盘不是负担，是第二天少踩坑的复利
