# marginal-tracker · 多市场股票投资论点边际跟踪器

> **一句话定位**：投资论点持续监控 + 证伪条件 · 6 维度 GUI 审查页面

---

## 这个 case 是什么

**页数**：4 页 · **领域**：金融投资

## 核心论点

投资论点不该只买入时建立 · marginal-tracker = 论点建立 + 6 维度持续监控 + 证伪条件 = 知道什么时候该退出。

## 6 维度监控

| 维度 | 监控指标 |
|---|---|
| 财务 | 营收/净利/现金流/资产负债 |
| 估值 | PE/PB/PS/DCF |
| 股价 | 现价/涨跌幅/关键支撑阻力 |
| 催化剂 | 已发生 + 即将发生 |
| 行业指标 | 上游/下游/竞争对手 |
| 证伪条件 | 何时该退出 |

## 4 步工作流

1. 论点建立（买入/卖出 + 关键假设 + 时间表）
2. 指标设定（财务 + 估值 + 股价 + 催化剂 + 行业 + 证伪）
3. 持续监控（每周/每月更新）
4. 输出（visual-page skill → GUI 审查页面）

## 不适用

- ❌ 一般新闻摘要
- ❌ 个人交易建议
