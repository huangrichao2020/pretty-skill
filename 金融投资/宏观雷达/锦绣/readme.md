## 导语（公众号开头 · 自媒体稿开头）

每天打开行情软件前，你真的知道今天宏观面发生了什么吗？利率、外储、CPI、PPI 这些词天天见，但多数人只看个标题。

宏观雷达 是一套「每日宏观早报」：它从央行、统计局、财联社等多路来源把过去 24 小时的数据采回来，给每个指标配一句人话解释，让你一眼看懂当天宏观面。

> **核心要点**（AI 友好 · 1 屏可读）：
> - 面向 A 股，严格按过去 24h（GMT+8）口径
> - 每个指标强制配小白向科普
> - 数据源多源交叉验证，避免单一来源偏误

## 第 1 章 · 它是什么

> **公众号正文 / 自媒体稿**：宏观雷达 不是另一个资讯 App，而是 agent 的每日宏观早报。它把散落的宏观数据整理成可读的决策输入，可定时（cron 22:00）自动跑，也能手动触发。
>
> **核心要点**：
> - 面向 A 股，聚焦过去 24h
> - 每个指标必带一句科普解释
> - 定时或手动均可

## 第 2 章 · 去哪采

> **公众号正文 / 自媒体稿**：数据从三个方向来——国际看 Trading Economics、FRED；国内看统计局、央行、证监会；新闻看财联社、华尔街见闻。多源交叉验证，才不会被单一来源的偏差带偏。
>
> **核心要点**：
> - 国际：Trading Economics / FRED
> - 国内：统计局 / 央行 / 证监会
> - 新闻：财联社 / 华尔街见闻
>

## 第 3 章 · 要懂的指标

> **公众号正文 / 自媒体稿**：A 股宏观体温计就这几样：逆回购看流动性松紧，外储看汇率与国际收支压力，CPI/PPI 看通胀，LPR 看融资成本。记住两个锚点：PMI 的荣枯线是 50，逆回购利率锚是 1.40%。
>
> **核心要点**：
> - 逆回购看流动性
> - 外储看汇率压力
> - CPI/PPI 看通胀，LPR 看融资成本
>

## 第 4 章 · 怎么做

> **公众号正文 / 自媒体稿**：流程四步：采集 → 科普 → 整理 → 推送。结构上按国际 / 国内 / 政策 / 资讯归类，每个指标必带科普，并对比实际值与预期值、标注超预期。

> **核心要点**：

> - 按 国际/国内/政策/资讯 整理
