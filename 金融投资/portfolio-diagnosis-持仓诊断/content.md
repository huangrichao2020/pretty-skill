## P0 · 封面 / 定位

- **标题**：持仓诊断
- **副标**：组合体检 · 四层融合 + A/B/C/D 分级
- **章节类型**：封面
- **核心主张**：持仓诊断不是逐只点评，是用**四层融合框架**对整个组合做体检，按 A/B/C/D 分级给出短期/中期操作建议；L0 有否决权
- **认知锚点**：「四层融合 + A/B/C/D 分级」
- **关键要点**：

  - 输出：分级评级 + 短期/中期操作建议
  - 触发：分析持仓 / 诊断持仓 / 看看我的股票 / 持仓复盘
- **数据 / 数字**：4 层 / 4 评级（A/B/C/D）/ 3 时间维度（24h/7d/长期）
- **金句**：组合体检 = 知道哪只该加，哪只该减，哪只该清

## P1 · 痛点切入

- **标题**：为什么"持仓诊断"90% 翻车
- **副标**：逐只点评 vs 组合体检
- **章节类型**：核心解法
- **核心主张**：90% 持仓诊断翻车是因为逐只点评（每只都说"持有"/"止损"）——没分级、没组合视角、没 L0 否决
- **认知锚点**：「4 大诊断翻车坑」

```text
翻车坑 1：逐只点评
  表现：每只都说"持有/止损"，没差异化
  解决：A/B/C/D 分级 + 组合视角

翻车坑 2：技术面 only
  表现：只看 K 线 / 均线 / 量能
  解决：四层融合（技术+情绪+产业+证据）

翻车坑 3：无 L0 否决
  表现：每只都说"好"但市场崩了
  解决：L0 5 维住相信号先判断（≥3 灯 = 全组合减仓）

翻车坑 4：没时间维度
  表现：只说"现在"该买该卖
  解决：24h（操作） / 7d（机会） / 长期（持有）三维度
```

- **数据 / 数字**：4 大坑 / 90% 翻车率
- **金句**：诊断不是"建议买/卖"，是"建议加/减/清"

## P2 · 四层融合 × 持仓组合

- **标题**：L0/L1 整体 + L2/L3 逐只
- **副标**：先看市场（L0/L1），再看个股（L2/L3）
- **章节类型**：核心解法
- **核心主张**：持仓诊断的 4 层 = L0/L1 整体判断（市场） + L2/L3 逐只判断（个股）；L0 一票否决时，再好的个股都减
- **认知锚点**：「L0/L1 整体 × L2/L3 逐只」

```text
L0 整体（最高否决权）
  对组合：5 维住相信号
  判定：≥3 灯 = 整体减仓信号生效（不逐只看）

L1 整体
  对组合：当前 STW 情绪周期
  判定：冰点/退潮 = 防御；复苏/高潮 = 进攻

L2 逐只
  对每只：行业有真实逻辑吗？
  检查：政策催化 / 业绩兑现 / 供需拐点 / 题材轮动

L3 逐只
  对每只：证据等级
  评级：Tier A（趋势确认）/ B（有逻辑待验证）/ C（情绪修复）/ D（高风险）
```

- **关键要点**：
  - **L0 优先**：L0 崩了 = 整个组合减仓，不看 L2/L3
  - **L1 次优**：L1 退潮 = 整体防御
  - L2/L3 决定"每只具体怎么操作"
  - 不分级的诊断 = 没诊断
- **数据 / 数字**：L0/L1 整体 + L2/L3 逐只
- **金句**：L0 崩了 = 不看 L2/L3，全减

## P3 · A/B/C/D 分级评级

- **标题**：A 持有 / B 观察 / C 减仓 / D 清仓
- **副标**：4 评级 + 操作建议
- **章节类型**：核心解法
- **核心主张**：分级评级 = 把 L2/L3 的诊断翻译成可执行操作；每只按 4 级分类，组合视图
- **认知锚点**：「A/B/C/D 分级」

```text
A 级 · 持有
  含义：有题材 + 有逻辑 + 有催化
  操作：持有，关注催化兑现
  时间：7d / 长期

B 级 · 观察
  含义：有逻辑但短期降温
  操作：等二次启动信号
  时间：7d

C 级 · 减仓
  含义：无独立催化，随大盘波动
  操作：趁反弹减仓
  时间：24h / 7d

D 级 · 清仓
  含义：高风险（ST / 立案 / 退市 / 套牢）
  操作：优先处理，止损或观望
  时间：24h
```

- **关键要点**：
  - A/B/C/D 不是"评分"，是"操作建议"
  - D 级优先于 A 级处理（D 风险无限，A 收益有限）
  - 同一组合内 A/B/C/D 比例反映组合质量
  - 健康组合：A > B > C > D（A 越多越好，D 必须 0）
- **数据 / 数字**：4 评级 / 时间维度 / 操作建议
- **金句**：D 级 0 只 = 组合健康的第一步

## P4 · 输出 widget 结构

- **标题**：可视化诊断 widget · 6 大区块
- **副标**：汇总 + 全景表 + 每只详情 + 操作建议
- **章节类型**：核心解法
- **核心主张**：诊断输出必须可视化、易操作，6 大区块按"汇总→全景→每只→操作"递进
- **认知锚点**：「6 区块 widget」

```text
Widget 6 大区块
  1 标题：持仓诊断 · 四层融合分析
  2 汇总区：总市值 / 总浮亏 / 总亏损率 / 今日变动
  3 持仓全景表：按 A/B/C/D 分级排列
    每只：股票名 / 市值 / 亏损% / 成本→现价 / 今日涨跌 / 板块 / 评级
  4 每只详情：四层评估
    L0 整体：当前信号灯
    L1 STW：市场温度
    L2 产业：行业逻辑
    L3 证据：Tier 等级
  5 操作建议：24h / 7d / 长期 三维度
  6 风险提示：L0 减仓信号 / 整体防御信号
```

- **关键要点**：
  - 表格优先：用户一眼能看到全部持仓
  - 颜色编码：A 绿 / B 蓝 / C 黄 / D 红
  - 汇总区放最上面（总市值 + 总亏损率 = 风险感）
  - 操作建议必给 3 时间维度
- **数据 / 数字**：6 区块 / 4 分级 / 3 时间维度
- **金句**：可视化 = 1 眼 get 组合全貌

## P5 · 默认设置 + 路由 + 怎么用

- **标题**：默认 4 层 + 4 评级 · 输入 3 方式 · 输出 widget
- **副标**：拿来即用
- **章节类型**：收束
- **核心主张**：本 skill 默认 4 层 + 4 评级 + widget 输出，**输入 3 方式**（截图/文本/口头）+ **输出 6 区块**
- **认知锚点**：「默认 + 输入输出」

```text
3 输入方式
  截图：券商 App 持仓页 → OCR/视觉识别提取

  口头：提到几只股票名

6 输出区块（widget 渲染）
  标题 / 汇总 / 全景 / 详情 / 操作 / 风险

4 评级操作
  A 持有 / B 观察 / C 减仓 / D 清仓

4 层融合
  L0 5 维信号（先判整体）
  L1 STW 周期（先判整体）
  L2 产业逻辑（逐只）
  L3 证据等级（逐只）

数据源
  行情：腾讯 API 实时
  板块：WebSearch（政策/业绩/事件）
```

- **关键要点**：
  - 与 `daily-market-review-每日复盘` 互补：复盘是"市场体检"，诊断是"组合体检"
  - 与 `serenity-stock-choke-A股卡脖子` 互补：卡脖子是"产业链分析"，诊断是"组合分析"
  - 与 `technical-signal` 互补：技术面是"个股技术分析"，诊断是"组合诊断"
  - 持仓健康 = A 多 D 少 + L0 不崩 + L1 顺势
- **数据 / 数字**：3 输入 / 6 输出 / 4 评级 / 4 层
- **金句**：组合体检 = 知道哪只加 / 减 / 清
