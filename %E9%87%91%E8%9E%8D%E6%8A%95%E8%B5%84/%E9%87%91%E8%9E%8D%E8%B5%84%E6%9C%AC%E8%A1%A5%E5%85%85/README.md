# 金融资本补充 (capital-injection-bank-insurance)

> **体系内闭环资本补充事件深度分析 · 不从二级市场抽血**

## 简介

A 股银行、保险、政策性银行的**定增/注资/资本补充事件**专用 skill，覆盖机制、工具、历史、当前信号。与制造业定增（idea-trade-qa 主战场）形成完整对比。

## 4 大核心概念

### 1. 触发原因：监管资本要求
- 商业银行资本充足率红线：核心一级 ≥7.5%（系统重要性银行 8.5%）
- 保险公司偿付能力：综合 ≥100%，核心 ≥50%
- 系统重要性银行升组 → 更高附加资本要求

### 2. 资本工具 4 大类
- **核心一级资本**（普通股、留存收益、IPO/定增）
- **其他一级资本**（优先股、永续债）
- **二级资本**（二级资本债，5+5 年期）
- **内源补充**（利润留存，受净息差约束）

### 3. 触发条件 3 大类
1. 资本充足率不达标或接近红线
2. 业务扩张需要资本支撑
3. 内源补充乏力（净息差收窄）

### 4. 与制造业定增的本质区别

| 维度 | 制造业 | 银行保险 |
|---|---|---|
| 触发原因 | 主业扩产 | 监管资本 |
| 认购方 | 散户 + 机构 + 大股东 | 体系内（财政部/烟草/汇金）|
| 二级抽血 | 是 | **否（核心特征）** |
| 锁定期 | 6-18 月 | **5 年** |
| 信号 | 看投向与业绩 | 看资本充足率 |
